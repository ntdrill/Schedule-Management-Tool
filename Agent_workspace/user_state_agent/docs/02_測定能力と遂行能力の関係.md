# 測定能力と遂行能力の関係

本システムの核となるロジックは、ユーザーの「測定能力」と「遂行能力」の相互依存関係に基づいています。

## 1. アンカー仮説

> **「測定可能な状態が遂行能力を保証する」**

ユーザーがタスクを遂行できるかどうかは、意志の強さではなく、「自身を客観的に測定（モニタリング）できているか」に依存するという仮説です。測定は、カオス的な内部状態を秩序ある状態へと繋ぎ止める「命綱」として機能します。

## 2. 測定能力 (Measurement Capability)

単にデータを記録することではなく、自身および他者の状態を客観的に観測し、確定させるメタ認知能力を指します。

*   **構成要素**:
    *   **感覚受容精度**: 身体感覚（Interoception）を正確に知覚できるか。
    *   **言語化能力**: 感覚を記号（例：「疲れている」「焦っている」）に変換できるか。
    *   **持続的注意**: モニタリング行為を継続する力。
*   **決定因子**:
    *   **脳の報酬系**: ドーパミン作動性ニューロンの活動レベルが、測定という「報酬の遅延を伴う行為」の持続性を決定する。
    *   **環境エントロピー**: 環境が散らかっていると認知リソースが奪われ、測定能力が低下する。

## 3. 動作モードの切り替え

システムは測定能力の状態に応じて、2つのモードを動的に切り替えます。

### 決定論的モード (Deterministic Mode)
*   **条件**: 測定能力が高く、測定状態が維持されている。
*   **挙動**:
    *   ユーザーは計画されたタスクを意図通りに実行できると仮定される。
    *   システムは効率的なスケジュール管理、複雑なタスクの提案を行う。
    *   「予定」と「実績」の乖離は最小化される。

### 確率的モード (Probabilistic Mode)
*   **条件**: 測定能力が閾値を下回り、測定状態が維持できない（ドロップアウト）。
*   **挙動**:
    *   ユーザーの行動は予測不可能（カオス・確率的）になる。過集中や逃避行動のリスクが高まる。
    *   システムは「タスク遂行」の支援を停止し、「測定能力の回復（リカバリー）」へ優先度を切り替える。
    *   提示されるタスクは単純な「呼吸法」「片付け」などに限定される。

## 4. 介入戦略

確率的モード（測定不能状態）に陥った場合、システムは以下の手順で介入します。

1.  **環境介入**: 「机の上を片付ける」「換気をする」など、環境エントロピーを下げることで認知リソースを回復させる。
2.  **生理的介入**: 「深呼吸」「水分摂取」など、自律神経バランスを整える。
3.  **測定復帰**: 測定能力が回復した時点で、再び決定論的モードへ移行し、通常のタスク管理を再開する。
