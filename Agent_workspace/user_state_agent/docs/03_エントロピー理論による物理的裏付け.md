# エントロピー理論による物理的裏付け

ユーザー状態の管理は、抽象的な概念だけでなく、物理学（熱力学・統計力学）および情報理論に基づくエントロピー計算によって裏付けられています。

## 1. 熱力学的エントロピー (Thermodynamic Entropy)

人体活動に伴う物理的なエントロピー生成を計算モデルに組み込んでいます。6畳室（約24m³、298K）をモデルとした計算例は以下の通りです。

*   **エントロピー生成の源**:
    *   **顕熱 (Sensible Heat)**: 人体からの発熱（約100W）。生成率 $\approx 0.34 \text{ W/K}$。
    *   **潜熱 (Latent Heat)**: 呼気や発汗による水蒸気放出（約10W）。生成率 $\approx 0.03 \text{ W/K}$。
    *   **外部仕事の散逸**: 摩擦や衝突により熱化する運動エネルギー。
*   **ネゲントロピー（負のエントロピー）**:
    *   生命活動（秩序維持）には、低エントロピー資源（食物＝化学自由エネルギー）の摂取が必要。
    *   秩序を生成・維持するプロセス（片付け、体内修復）は、必ず外部への熱エントロピー排出（散逸）を伴う。
    *   **結論**: 「整理された状態」を作るためには、その代償として熱エネルギーを消費し、環境のエントロピーを増大させる必要がある。

## 2. 情報エントロピー (Information Entropy)

状態の「不確かさ」や「散らかり具合」を定量化します。

*   **定義**: シャノンエントロピー $H(X) = -\sum p_i \log_2 p_i$
*   **適用例**:
    *   **環境の散らかり**: 物の配置パターンの不確かさとして計算。
    *   **脳内の雑然さ**: 思考や注意の分散度合い。セロトニン等の神経伝達物質は、この情報エントロピーを下げる「整理因子」として機能すると解釈される。

## 3. ユーザーエントロピー (User Entropy)

システム独自の指標として、ユーザーの状態安定度を定義します。

*   **定義**: ユーザーの内部状態（生理指標・心理指標）の分散。
*   **閾値管理**:
    *   `x_3`: 作業開始可能状態の上限値。これを超えると作業に着手できない。
    *   `x_4`: 作業継続可能状態の上限値。これを超えると休憩が必要。
*   **関係性**: 環境エントロピーが増大すると、ユーザーエントロピーも連動して増大する傾向がある（環境分散がユーザー分散に波及する）。

## 4. 計算の実践例（エントロピー収支）

*   **「食べる→皿洗い（30分）」**:
    *   熱エントロピー生成: $\approx 0.85 \text{ kJ/K}$
    *   混合エントロピー生成: $\approx 0.10 \text{ kJ/K}$
    *   **合計**: $\approx 0.95 \text{ kJ/K}$ のエントロピーを環境に排出することで、食事（エネルギー摂取）と皿洗い（環境秩序回復）を行っている。
*   **「PC作業（60分）」**:
    *   **合計**: $\approx 1.59 \text{ kJ/K}$ （主に人体とPCの発熱による）。

システムはこの「コスト（熱排出）」と「成果（秩序回復）」のバランスを評価し、効率的な状態管理を支援します。
