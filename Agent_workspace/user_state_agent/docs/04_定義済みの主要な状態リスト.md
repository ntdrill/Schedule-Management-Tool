# 定義済みの主要な状態リスト

システムで定義されている具体的なユーザー状態とその判定条件（抜粋）です。これらは「状態スキーマ」として実装され、タスクの前提条件や目標状態として使用されます。

## 1. 安定・準備状態

### @標準状態
心身ともに安定したベースライン状態。
*   **判定条件**:
    *   心拍数: 55~65
    *   酸素レベル: 96%以上
    *   睡眠: 18時間以内に質の高い睡眠から覚醒
    *   栄養・睡眠サイクルの維持（3日以上）
    *   心理的抑制状態ではない
    *   心理的安全性を自身で再現できる

### @作業開始可能状態
高い集中力を発揮できる準備が整った状態。
*   **判定条件**:
    *   酸素レベル: 97%以上
    *   心拍数: 60~70
    *   換気: 10分以上実施済み
    *   環境エントロピー $\le x_2$
    *   ユーザーエントロピー $\le x_3$

### @清掃開始可能状態
掃除というエントロピー減少活動を行うための特殊モード。
*   **判定条件**:
    *   作業開始可能状態を満たす
    *   「掃除屋理論」について想起している

## 2. 作業・集中状態

### @作業継続可能状態
作業を継続してもパフォーマンスが維持できる状態。
*   **判定条件**:
    *   酸素レベル: 97%以上
    *   心拍数: 70~80
    *   換気: 1時間以内に実施
    *   ユーザーエントロピー $\le x_4$

### @作業時DMN活性状態
デフォルト・モード・ネットワーク（DMN）が適切に活性化している状態。
*   **判定条件**:
    *   耳栓または無音環境から15分以上経過
    *   標準状態を満たす

### @過集中・覚醒（危篤状態）
交感神経が過剰に優位で、ブレーキが効かない危険な状態。
*   **判定条件（いずれかまたは複合）**:
    *   脈拍: 80~90以上で下がらない
    *   イベント境界の喪失（太極拳時と比較して）
    *   呼吸が浅い、鈍い頭痛
    *   作業時間: 休憩なしで2時間以上経過
    *   就寝予定1時間前なのに作業を止められない
    *   硬い炭水化物を3時間以内に摂取

## 3. 抑制・不調状態

### @心理的抑制状態
メンタルブロックがかかり、行動が阻害されている状態。
*   **判定条件**:
    *   解決しない心理的問題があると感じる
    *   問題の原因や対処法がわからない、または実施できない

### @不安障害状態
自己コントロールが困難で、システム介入が必要な状態。
*   **判定条件**:
    *   心理的抑制状態である
    *   感受性状態や心理的安全性を再現できない
    *   身体的不調を非自明な仮説で説明しようとする

### @表現力状態
*   **定義**: 「自分はどこにもいない」という感覚（解離の一種、または没入状態）。

### @感受性状態
*   **定義**: 苦痛について想起している状態。
