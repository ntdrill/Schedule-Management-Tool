提示された項目に加え、システムの拡張性や管理のしやすさを考慮して、いくつか追加・調整案を提案します。

### 基本案（提示された項目）

1.  **`symbol`** (TEXT, Primary Key): 記号（Unicode文字）。一意の識別子。
2.  **`name`** (TEXT): 名前（プログラム上の変数名など）。
3.  **`description`** (TEXT): 説明文。
4.  **`category`** (TEXT): 定数・変数・変換・関数などの分類。
5.  **`signature`** (JSONB or TEXT): 入力値・出力値・引数などの型情報や構造。

### 追加・調整の提案

これらに加えて、以下のカラムがあると便利です：

6.  **`group_id`** (TEXT): より大きな分類（例: `Physical Constants`, `System Settings`, `User State` など）。`data/constants.txt` などのファイル単位や、エージェントごとの管轄を示すのに使えます。
7.  **`default_value`** (JSONB): 定数の場合の初期値や、変数の初期状態。JSONB型にすることで、数値、文字列、オブジェクトなど多様な型を格納できます。
8.  **`unit`** (TEXT): 単位（分, W, K, % など）。物理定数には必須です。
9.  **`is_active`** (BOOLEAN): 現在使用されているかどうかのフラグ。廃止されたシンボルを論理削除扱いにできます。
10. **`created_at`**, **`updated_at`** (TIMESTAMPTZ): 作成日時、更新日時。

### 推奨スキーマ構成（SQL）

これらをまとめると、Supabase（PostgreSQL）のテーブル作成クエリは以下のようになります。

```sql
CREATE TABLE symbols (
    symbol TEXT PRIMARY KEY,          -- 記号 (例: '🀰')
    name TEXT NOT NULL UNIQUE,        -- 名前 (例: 'tau_dish_washing')
    description TEXT,                 -- 説明
    category TEXT NOT NULL,           -- 分類 ('constant', 'variable', 'function' など)
    group_id TEXT,                    -- グループ ('physical_constants', 'user_state' など)
    
    -- データ型や関数のシグネチャ詳細
    signature JSONB DEFAULT '{}',     -- { "input": "...", "output": "...", "args": [...] }
    
    -- 値に関する情報
    default_value JSONB,              -- 初期値/定数値 (JSON形式)
    unit TEXT,                        -- 単位 (例: 'min', 'W')
    
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

この構成であれば、`constants.txt`（定数）、`variables.txt`（変数）、`transforms.txt`（関数）の全てを一つのテーブルで柔軟に管理できます。

### スクリプトの概要

1.  **パース処理**:
    *   各テキストファイルを読み込み、`記号 名前: 説明 (補足情報)` の形式を解析します。
    *   ファイルの種類に応じて `category` と `group_id` を自動設定します。
        *   `constants.txt`: `category='constant'`, `group_id` は記号種別（ドミノ横/縦）で判定
        *   `variables.txt`: `category='variable'`
        *   `transforms.txt`: `category='function'`
    *   `( )` 内の情報を `default_value` や `unit` として抽出を試みます。

2.  **登録処理**:
    *   解析したデータを `symbols` テーブルに `upsert`（挿入または更新）します。

3.  **検証処理** (`01_DB導入と登録フロー策定.txt` の要件):
    *   登録しようとした件数と、登録成功した件数を照合し、結果を表示します。

```python
import re
import os
from typing import List, Dict, Any, Optional
from supabase import create_client, Client

# --- Configuration ---
SUPABASE_URL = "https://nonrlrdalfefykzborvm.supabase.co"
SUPABASE_KEY = "sb_publishable_3H0ns8nZBmJuAhOgCUd0gw_sTURYilU" # Provided key

# File paths
DATA_DIR = "data"
FILES = {
    "constants.txt": {"category": "constant"},
    "variables.txt": {"category": "variable"},
    "transforms.txt": {"category": "function"},
}

# --- Parsing Logic ---
def parse_line(line: str, file_name: str, default_category: str) -> Optional[Dict[str, Any]]:
    line = line.strip()
    if not line or ":" not in line:
        return None

    # Basic Split: Symbol Name: Description (Extra)
    # Example: 🀰 tau_dish_washing: 皿洗いの単位処理時間 (1.0分/個)
    
    # 1. Extract Symbol (First character usually, but need to be careful with surrogate pairs)
    # Using regex to capture the first "word" as symbol (assuming no spaces in symbol)
    match = re.match(r"^(\S+)\s+([^:]+):\s*(.+)$", line)
    if not match:
        print(f"Skipping format mismatch: {line}")
        return None
    
    symbol = match.group(1)
    name = match.group(2).strip()
    rest = match.group(3).strip()
    
    description = rest
    default_value = None
    unit = None
    
    # Try to extract content in parentheses as default value / unit
    # This is a heuristic and might need adjustment based on exact formatting
    paren_match = re.search(r"\((.+)\)$", rest)
    if paren_match:
        content_in_paren = paren_match.group(1)
        description = rest.replace(f"({content_in_paren})", "").strip()
        
        # Simple heuristic for Unit vs Value
        # If it looks like "1.0分/個", it's value + unit
        # If it looks like "ISO 8601", it's format/type info (can be signature)
        
        # Store raw paren content as default_value for now, can be refined manually later
        default_value = content_in_paren

    # Determine Group ID based on file and symbol characteristics
    group_id = "general"
    if file_name == "constants.txt":
        # Check symbol range for Physics vs System
        if "\U0001f030" <= symbol <= "\U0001f03f": # Domino Horizontal
            group_id = "physical_constants"
        elif "\U0001f060" <= symbol <= "\U0001f09f": # Domino Vertical
            group_id = "system_settings"
        else:
            group_id = "constants_misc"
            
    elif file_name == "variables.txt":
        if "\U0001f000" <= symbol <= "\U0001f02b": # Mahjong
            group_id = "state_variables"
        elif symbol in ["┝", "┠", "┣", "╏", "║", "│"]: # Box Drawing
            group_id = "containers"
        else:
            group_id = "variables_misc"
            
    elif file_name == "transforms.txt":
        group_id = "functions"

    return {
        "symbol": symbol,
        "name": name,
        "description": description,
        "category": default_category,
        "group_id": group_id,
        "default_value": {"raw": default_value} if default_value else None,
        "unit": unit # Parsing unit strictly is hard without strict format
    }

def process_files() -> List[Dict[str, Any]]:
    records = []
    print("--- Parsing Files ---")
    for filename, config in FILES.items():
        filepath = os.path.join(DATA_DIR, filename)
        if not os.path.exists(filepath):
            print(f"Warning: File not found {filepath}")
            continue
            
        print(f"Reading {filename}...")
        count = 0
        try:
            with open(filepath, 'r', encoding='utf-8') as f:
                for line in f:
                    record = parse_line(line, filename, config["category"])
                    if record:
                        records.append(record)
                        count += 1
            print(f"  -> Found {count} records in {filename}")
        except Exception as e:
            print(f"Error reading {filename}: {e}")
            
    return records

# --- Database Logic ---
def push_to_supabase(records: List[Dict[str, Any]]):
    if not records:
        print("No records to push.")
        return

    print("\n--- Connecting to Supabase ---")
    try:
        supabase: Client = create_client(SUPABASE_URL, SUPABASE_KEY)
        
        print(f"Attempting to upsert {len(records)} records...")
        
        # Supabase (PostgREST) allows bulk upsert
        # upsert returns data, count, error
        response = supabase.table("symbols").upsert(records, on_conflict="symbol").execute()
        
        # Check response (format depends on library version, usually .data contains inserted rows)
        if response.data:
            inserted_count = len(response.data)
            print(f"\n--- Success! ---")
            print(f"Registered/Updated: {inserted_count} records")
            
            # Verification Logic (Count Check)
            if inserted_count == len(records):
                print("✅ Count Check Passed: Input count matches Database count.")
            else:
                print(f"⚠️ Count Check Failed: Input {len(records)} != Database {inserted_count}")
        else:
             # If data is empty but no exception, might be an issue or just no changes returned?
             # Usually execute() raises exception on error
             print("Response contained no data. Check table permissions or format.")

    except Exception as e:
        print(f"\n❌ Error pushing to Supabase: {e}")
        # print(e) # Uncomment for debug details

if __name__ == "__main__":
    data = process_files()
    if data:
        push_to_supabase(data)
    else:
        print("No data parsed.")
```
