# 実装エージェント一覧

本プロジェクトの実装を担当する専門家エージェントのレジストリです。
各エージェントは特定の「観点」を持ち、その領域の実装に責任を持ちます。

## マネジメント
| エージェント名 | パス | 担当観点 | 責任範囲 |
| :--- | :--- | :--- | :--- |
| **Agent_Manager** | `Agent_workspace/Agent_maneger` | プロジェクト管理、観点の補充 | 全体進捗の管理、エージェント間の調停、タスクの割り振り |

## 状態モデル担当
| エージェント名 | パス | 担当観点 | 責任範囲 |
| :--- | :--- | :--- | :--- |
| **User_State_Agent** | `Agent_workspace/user_state_agent` | ユーザー状態、生理的指標 | ユーザー状態スキーマの定義、判定ロジック、危篤状態の検知 |
| **Environment_State_Agent** | `Agent_workspace/environment_state_agent` | 環境状態、エントロピー | 環境状態スキーマの定義、掃除タスクによるネゲントロピー計算 |
| **Social_State_Agent** | `Agent_workspace/social_state_agent` | 社会的状態、組織構造 | 社会的状態スキーマの定義、組織エントロピー、他者との接続性 |
| **Monitoring_State_Agent** | `Agent_workspace/monitoring_state_agent` | 測定、モニタリング | 測定モードの仕様策定、センサー連携の設計 |
| **Organization_State_Agent** | `Agent_workspace/organization_state_agent` | 組織論、ペアリング | (Social_State_Agentと統合検討中) 組織エントロピーの詳細定義 |

## システム基盤担当
| エージェント名 | パス | 担当観点 | 責任範囲 |
| :--- | :--- | :--- | :--- |
| **Symbol_Agent** | `Agent_workspace/symbol_agent` | 記号接地、データ構造 | 辞書.yamlの管理、概念と実装の紐付け、ID体系の管理 |
| **Task_Queue** | `Agent_workspace/task_queue` | タスク処理、非同期連携 | (現状は値の提案置き場として機能) 実装タスクのバッファ |
