先ほどの方法論に従い、**Phase 2: 相互作用（Interactions）** のワークフローを考案します。

---

## Phase 2 の定義

| 項目 | 内容 |
| :--- | :--- |
| **目的** | 2つ以上のエージェント領域が関わる処理をスナップショット化する |
| **入力** | Phase 1 で作成された基礎スナップショット + 相互作用のユースケース |
| **出力** | 複合的なスナップショット（基礎スナップショットを組み合わせた論理式） |
| **例** | 「環境悪化がユーザー状態に影響」「タスク完了と状態評価の連動」 |

---

## Agent_Workflow_Queue (Phase 2: Interactions)

1. **Agent_Manager**: `Task_Management/02_Active` に親タスク `task_Phase2_Interactions.txt` を作成する
2. **Agent_Manager**: Phase 1 の成果物（スナップショット）を参照可能な状態にする
3. **Agent_Manager**: `task_Phase2_Interactions.txt` 内で、各専門エージェントに「他領域との相互作用ユースケース」の提出をアサインする
4. **User_State_Agent**: `Task_Management/01_Proposals` に `proposal_user_interaction.txt` を作成する
5. **Environment_State_Agent**: `Task_Management/01_Proposals` に `proposal_env_interaction.txt` を作成する
6. **Social_State_Agent**: `Task_Management/01_Proposals` に `proposal_social_interaction.txt` を作成する
7. **Agent_Manager**: `Task_Management/01_Proposals` を監視し、ファイルが提出されたことを検知する
8. **Agent_Manager**: 提出された `proposal_*_interaction.txt` を読み込み、内容が適切か確認する
9. **Agent_Manager**: 確認した `proposal_*_interaction.txt` を `Task_Management/02_Active` に移動する
10. **Agent_Manager**: `task_Phase2_Interactions.txt` を更新し、Symbol_Agent に「相互作用シンボルの抽出と定義」を指示する
11. **Symbol_Agent**: `Task_Management/02_Active` に移動されたユースケースファイルを読み込む
12. **Symbol_Agent**: 相互作用に必要な概念（領域間の変換、因果関係など）を抽出してリスト化する
13. **Symbol_Agent**: Phase 1 で定義済みのシンボルと照合し、不足分を特定する
14. **Symbol_Agent**: 不足分に対して新しいシンボルを設計し、`data/` 内の適切な辞書ファイルに追記する
15. **Symbol_Agent**: `Task_Management/02_Active` に `report_symbol_definition_Phase2.txt` を作成し、定義結果を報告する
16. **Symbol_Agent**: `task_Phase2_Interactions.txt` に「シンボル定義完了」を追記する
17. **Agent_Manager**: シンボル定義報告を確認し、Data_Model_Agent に「相互作用スナップショット記述」を指示する
18. **Data_Model_Agent**: Phase 1 のスナップショットを部品として読み込む
19. **Data_Model_Agent**: Phase 2 のユースケースファイルと、更新された `data/` を読み込む
20. **Data_Model_Agent**: 基礎スナップショットを組み合わせ、相互作用を表す論理式を作成する
21. **Data_Model_Agent**: `Agent_workspace/data_model_agent/業務/02_相互作用スナップショットの記述.txt` に論理式を追記する
22. **Data_Model_Agent**: `task_Phase2_Interactions.txt` に作業完了を追記する
23. **Agent_Manager**: 成果物（相互作用スナップショットファイル）を確認し、最終承認を行う
24. **Agent_Manager**: `Task_Management/02_Active` 内の `proposal_*_interaction.txt` を `Task_Management/03_Completed` に移動する
25. **Agent_Manager**: `Task_Management/02_Active` 内の `report_symbol_definition_Phase2.txt` を `Task_Management/03_Completed` に移動する
26. **Agent_Manager**: 親タスク `task_Phase2_Interactions.txt` を `Task_Management/03_Completed` に移動する
27. **Agent_Manager**: 完了したファイル群を `Task_Management/04_Archive/Phase2_Interactions_[日付]/` にアーカイブする
