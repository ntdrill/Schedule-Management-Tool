Phase 1〜3 で「ユースケース → スナップショット（シンボルによる論理式）」の記述が完了した後は、**抽象から具象へ（設計から実装へ）** 移行するフェーズが必要になると考えます。

---

## 後続フェーズの提案

### Phase 4: 構造抽出（Structure Extraction）
| 項目 | 内容 |
| :--- | :--- |
| **目的** | スナップショットから「名詞（データ）」と「動詞（処理）」を抽出し、リスト化する |
| **入力** | Phase 1〜3 のスナップショット群 |
| **出力** | クラス候補リスト、変数候補リスト、関数候補リスト |
| **担当** | Data_Model_Agent + Symbol_Agent |

### Phase 5: スキーマ定義（Schema Definition）
| 項目 | 内容 |
| :--- | :--- |
| **目的** | 抽出した構造を SwiftData のモデル定義（`@Model`）に落とし込む |
| **入力** | Phase 4 の候補リスト |
| **出力** | Swift の `.swift` ファイル（データモデル定義） |
| **担当** | Data_Model_Agent |

### Phase 6: デバイス分担設計（Device Assignment）
| 項目 | 内容 |
| :--- | :--- |
| **目的** | バージョン1方針（Local First / Watch Centric）に基づき、各処理を iPhone / Watch に割り当てる |
| **入力** | Phase 5 のスキーマ + バージョン1提案書 |
| **出力** | デバイス分担表（どのクラス・関数がどのデバイスに属するか） |
| **担当** | Agent_Manager + UI_Design_Agent |

### Phase 7: プロトタイプ実装（Prototype Implementation）
| 項目 | 内容 |
| :--- | :--- |
| **目的** | 最小限の機能（1〜2個のスナップショット）を実際の Swift コードで実装する |
| **入力** | Phase 5・6 の成果物 |
| **出力** | 動作する Xcode プロジェクト（iPhone / Watch） |
| **担当** | 開発者（人間） |

### Phase 8: 検証とフィードバック（Validation & Feedback）
| 項目 | 内容 |
| :--- | :--- |
| **目的** | 実装がスナップショットと整合しているかを検証し、乖離があれば修正する |
| **入力** | Phase 7 の実装 + Phase 1〜3 のスナップショット |
| **出力** | 検証レポート、修正タスク |
| **担当** | Agent_Manager + 開発者 |

---

## 全体の流れ（まとめ）

```
[抽象（設計）]
  Phase 1: 基礎動作 → スナップショット
  Phase 2: 相互作用 → スナップショット
  Phase 3: 複合・例外 → スナップショット
      ↓
[具象化（構造化）]
  Phase 4: 構造抽出 → クラス/変数/関数リスト
  Phase 5: スキーマ定義 → SwiftData モデル
  Phase 6: デバイス分担 → iPhone/Watch 割り当て
      ↓
[実装]
  Phase 7: プロトタイプ実装 → Swift コード
  Phase 8: 検証とフィードバック → 修正ループ
```
