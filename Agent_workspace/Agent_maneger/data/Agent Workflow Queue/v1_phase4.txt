**Phase 4: 構造抽出（Structure Extraction）** のワークフローを作成します。

---

## Phase 4 の定義

| 項目 | 内容 |
| :--- | :--- |
| **目的** | スナップショットから「名詞（データ）」と「動詞（処理）」を抽出し、クラス候補・変数候補・関数候補リストを生成する |
| **入力** | Phase 1〜3 のスナップショット群（`01_静的スナップショット`、`02_相互作用スナップショット`、`03_複合スナップショット`）+ `data/constants.txt`、`data/variables.txt`、`data/transforms.txt` |
| **出力** | クラス候補リスト、変数候補リスト、関数候補リスト（`04_構造抽出.txt`） |
| **例** | 「タスク」「ユーザー状態」→ クラス候補、「完了率」「負荷」→ 変数候補、「評価する」「遷移する」→ 関数候補 |

---

## Agent Workflow Queue (Phase 4: Structure Extraction)

1. **Agent_Manager**: `Task_Management/02_Active` に親タスク `task_Phase4_Structure.txt` を作成する
2. **Agent_Manager**: Phase 1〜3 の成果物（スナップショット群および `data/` 内のシンボル辞書）を参照可能な状態にする
3. **Agent_Manager**: `task_Phase4_Structure.txt` 内で、Symbol_Agent に「スナップショットからの名詞・動詞抽出」を、Data_Model_Agent に「候補リストの構造化」をアサインする
4. **Symbol_Agent**: `Agent_workspace/data_model_agent/業務/01_静的スナップショットの記述.txt`、`02_相互作用スナップショットの記述.txt`、`03_複合スナップショットの記述.txt` を読み込む
5. **Symbol_Agent**: `data/constants.txt`、`data/variables.txt`、`data/transforms.txt` を読み込み、既存シンボル辞書の内容を把握する
6. **Symbol_Agent**: スナップショット群から「名詞（データ実体）」を抽出してリスト化する
7. **Symbol_Agent**: スナップショット群から「動詞（処理・変換）」を抽出してリスト化する
8. **Symbol_Agent**: 抽出した名詞・動詞リストと既存シンボル辞書を照合し、既定義・未定義・新規候補を分類する
9. **Symbol_Agent**: `Task_Management/02_Active` に `report_symbol_extraction_Phase4.txt` を作成し、抽出結果と照合結果を報告する
10. **Symbol_Agent**: `task_Phase4_Structure.txt` に「シンボル抽出・照合完了」を追記する
11. **Agent_Manager**: 抽出報告を確認し、Data_Model_Agent に「候補リストの構造化」を指示する
12. **Data_Model_Agent**: `report_symbol_extraction_Phase4.txt` とスナップショット群を読み込む
13. **Data_Model_Agent**: 抽出された名詞を「クラス候補」と「変数候補」に分類し、リスト化する
14. **Data_Model_Agent**: 抽出された動詞を「関数候補」に分類し、リスト化する
15. **Data_Model_Agent**: `Agent_workspace/data_model_agent/業務/04_構造抽出.txt` にクラス候補リスト、変数候補リスト、関数候補リストを記述する
16. **Data_Model_Agent**: `task_Phase4_Structure.txt` に作業完了を追記する
17. **Agent_Manager**: 成果物（`04_構造抽出.txt`）を確認し、最終承認を行う
18. **Agent_Manager**: `Task_Management/02_Active` 内の `report_symbol_extraction_Phase4.txt` を `Task_Management/03_Completed` に移動する
19. **Agent_Manager**: 親タスク `task_Phase4_Structure.txt` を `Task_Management/03_Completed` に移動する
20. **Agent_Manager**: 完了したファイル群を `Task_Management/04_Archive/Phase4_Structure_[日付]/` にアーカイブする

## Phase 1・2・3・4 の全体比較

| 観点 | Phase 1 | Phase 2 | Phase 3 | Phase 4 |
| :--- | :--- | :--- | :--- | :--- |
| **ユースケースの焦点** | 単一領域内の処理 | 複数領域間の影響 | ループ・分岐・例外 | （なし：スナップショットからの逆引き） |
| **スナップショットの構造** | 単純な論理式 | Phase 1 の組み合わせ | Phase 1・2 + 制御構文 | 入力として参照 |
| **シンボル定義の焦点** | 基本的な名詞・動詞 | 領域間変換関数 | 制御演算子（ループ、分岐） | 既存辞書との照合・候補分類 |
| **主な作業フロー** | 提案→シンボル→スナップショット | 提案→シンボル→スナップショット | 提案→シンボル→スナップショット | スナップショット→抽出→照合→候補リスト |
| **成果物ファイル** | `01_静的スナップショット` | `02_相互作用スナップショット` | `03_複合スナップショット` | `04_構造抽出` |
| **ステップ数** | 24 | 27 | 27 | 20 |
