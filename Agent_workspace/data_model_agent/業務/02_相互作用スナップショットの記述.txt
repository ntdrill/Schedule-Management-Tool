# 業務: 相互作用スナップショットの記述

作成日: 2026/02/13  
担当: Data_Model_Agent

## 資料準拠（事実）
- Phase 2 の対象は「2つ以上のエージェント領域が関わる処理」。
- 入力は Phase 1 の基礎スナップショットと相互作用ユースケース。
- 環境悪化が測定能力を介してユーザー状態に波及する構造が前提。
- 測定疲労は測定能力低下と品質低下を引き起こしうる。
- 組織状態は相互測定エッジの集合として扱う。

## 相互作用スナップショット

### Snapshot P2-01: 環境悪化 -> 測定能力低下 -> 作業不能化
Expression:
`(ꀓ, ꁀ, ꀾ) ≫ (ꄐ(ꀓ, ꄀ) ⟼ ꀳ) ≫ ((ꀳ < ሤ) ⟼ ꄇ=false)`

### Snapshot P2-02: 換気不足 -> 空気質悪化 -> 測定品質低下
Expression:
`(ꀾ, ሷ) ≫ (⇗(ꀾ) ⟼ ꁤ) ≫ (ꄓ(ꀓ) ⟼ ꀤ) ≫ (ꀤ ↑ ∴ ꄌ ↓)`

### Snapshot P2-03: 測定能力喪失下の接触増加 -> エッジ弱化
Expression:
`(ꀳ, ━) ≫ (ꄑ(━, ꄅ) ⟼ ꄊ=true) ≫ (↭(━) ⟼ ꀢ ↑)`

### Snapshot P2-04: 測定疲労蓄積 -> 測定能力低下
Expression:
`(ꀡ, ꃅ) ≫ (⇹(ꀡ, ꃅ) ⟼ ꀟ) ≫ ((ꀟ >= ꄄ) ⟼ ꀳ ↓)`
