# エッジダイナミクスとエントロピー計算

## 1. 組織の分散 (Organization Variance)
*   **定義**: 組織を構成するエッジが解除され、構造としての結合力が失われていく状態。
*   **物理的解釈**: 構成員（粒子）が相互作用（測定）を失い、個別にランダムな運動を始めることによる「集団としての拡散」。

## 2. 組織エントロピーの定義式
組織エントロピーの変化量 $\Delta S_{org}$ は、とある時点 $t_1$ とそれより後の時点 $t_2$ における組織の分散 $V$ の差分として定義される。

$$ \Delta S_{org} = V(t_2) - V(t_1) $$

*   $\Delta S_{org} > 0$: 組織の秩序が崩壊しつつある（エッジが切れている）。
*   $\Delta S_{org} < 0$: 組織の結合が強化されている（ネゲントロピー生成）。

## 3. エッジ解除のダイナミクス
エッジの維持は相互の測定能力に依存するため、片方または両方の能力低下によって非対称な挙動を示す。

### 3.1 非対称解除（Asymmetric Dissolution）
*   **条件**: **片方の**測定能力が低下した場合。
*   **現象**: ペアリングは**徐々に**失われていく。
*   **メカニズム**:
    *   正常な側のユーザーによる一方的な測定（観測）が残っている。
    *   エッジは「双方向（Mutual）」から「片方向（Unilateral）」へと性質を変える。
    *   即座には霧散しないが、相互作用としての強度は弱まり、時間経過とともにエッジ強度は減衰（Decay）していく。
*   **システムの挙動**: エッジを「片方向モード」に移行させ、減衰係数を緩やかに設定する。

### 3.2 対称解除（Symmetric Dissolution）
*   **条件**: **両方の**測定能力が低下した場合。
*   **現象**: ペアリングは**直ちに**失われる（即時崩壊）。
*   **メカニズム**:
    *   相互に相手を定義・観測できなくなる。
    *   関係性は即座に「確率的なもの」へと退行し、構造としてのエッジを維持するエネルギーが消失する。
*   **システムの挙動**: 猶予を与えず、エッジを即時破棄（切断）し、組織エントロピー増大の警告を発する。
