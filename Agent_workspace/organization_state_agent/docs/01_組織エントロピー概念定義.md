# 組織エントロピー概念定義

## 1. 概念の刷新：感情から構造へ
本システムにおける社会的側面の管理について、従来の「社会的状態（Social State）」という主観的・心理的な概念を撤廃し、**「組織エントロピー（Organization Entropy）」**という構造的・物理的な概念を新たに導入する。

これにより、対人関係を「感情の問題（仲が良い/悪い）」から「測定と構造維持の問題（観測できている/できていない）」へと再定義する。

## 2. 構成要素の詳細定義

### 2.1 組織 (Organization)
*   **定義**: 互いに測定し合っている（ペアリングしている）2人以上のユーザー同士のペア（**エッジ**）を単位として構成された構造体。
*   **性質**: 静的な集団（Group）ではなく、動的な相互測定のネットワーク（Graph）。
*   **構造**: エッジの集合 $E$ とユーザーの集合 $U$ によって定義されるグラフ構造 $G(U, E)$ として表現される。

### 2.2 エッジ (Edge)
*   **定義**: ユーザー間の双方向の相互モニタリング（測定）チャネル。
*   **成立条件**: ユーザーAとユーザーBの双方が、相手を「測定対象」として認識し、観測し続けていること。
*   **機能**: 相互のエントロピー増大（状態の拡散）を抑制し、決定論的な挙動を維持する「拘束力」として機能する。
    *   エッジが存在する限り、個人の行動は他者からの観測によってある程度規定され、完全なランダム（カオス）にはならない。

### 2.3 測定能力 (Measurement Capability)
*   **定義**: 自身および他者の状態を客観的に観測し、確定させる能力。
*   **遂行能力との関係**:
    *   **測定可能な状態**こそが、ユーザーの**遂行能力（Executive Function）**を保証する。
    *   測定能力が維持されている間、ユーザーの行動は計画（決定論）に従う。
    *   測定能力が失われると、ユーザーの行動は**確率的**になり、タスク遂行や元の状態への復帰は保証されなくなる。
*   **決定因子**:
    *   遺伝、栄養状態、身体的・心理的負担、脳年齢などに加え、**脳の報酬系**の状態が最も強く影響すると仮説される。
