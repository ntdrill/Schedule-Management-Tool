# 組織崩壊のカスケードモデル

組織エントロピーの増大（組織の崩壊）は、単独で発生するものではなく、環境および個人の崩壊から連鎖的に発生する。この因果連鎖を3段階のフェーズで定義する。

## Phase 1: 環境の分散（Environment Variance）
*   **トリガー**: 物理的環境の無秩序化。
    *   部屋が散らかる（オブジェクト配置のエントロピー増大）。
    *   気温・湿度が不快なレベルになる。
    *   騒音などの環境ノイズが増大する。
*   **メカニズム**:
    *   環境からの入力情報量（ノイズ）が増大し、ユーザーの脳内処理リソースが環境スキャンとノイズ処理に奪われる。
    *   「片付けなければならない」という未完了タスク（Open Loops）がワーキングメモリを圧迫する。
*   **影響**: 認知リソースの枯渇が始まる。

## Phase 2: ユーザー状態の分散（User Variance）
*   **現象**: 環境の分散に引きずられ、ユーザー自身の内部状態（神経・生理）の分散が高まる。
    *   自律神経の乱れ（交感神経過活動など）。
    *   感情の不安定化。
*   **臨界点（Critical Point）**:
    *   ユーザーの分散が特定の閾値を超えると、自己をモニタリングする**「測定能力」が機能不全に陥る**。
    *   この時点から、ユーザーは自身の状態を客観視できなくなり、行動制御が「決定論的」から「確率的」へと退行する。
    *   遂行能力（Executive Function）の喪失。

## Phase 3: 組織エントロピーの増大（Organization Entropy）
*   **現象**: 自己測定能力を失ったユーザーは、他者を測定（ペアリング）する能力も同時に失う。
    *   他者への関心が消失する（認知リソースが自己防衛と環境対応で手一杯になるため）。
    *   相手からのシグナルを受信・処理できなくなる。
*   **結果**:
    *   エッジ（相互観測チャネル）が維持できなくなり解除される。
    *   組織全体の構造が崩壊し、個々のユーザーが孤立した粒子としてランダム運動を始める。
