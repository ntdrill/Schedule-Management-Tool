# 辞書・テンプレート管理マニュアル (Dictionary & Template Guide)

## 1. 目的
本マニュアルは、シンボル化されたデータの中で特に「辞書（Dictionary）」および「テンプレート（Template）」として扱われるデータの管理方法を定める。これらはユーザーが選択可能なプリセットデータであり、システムの拡張性を担う。

## 2. 管理対象
以下のデータ群を本マニュアルの管理対象とする。
*   **タスクテンプレート**: `task_templates_dictionary`
*   **リカバリータスク**: `recovery_task_templates`
*   **状態プリセット**: `state_schema_user`, `state_schema_environment` 等で定義される標準状態

## 3. 辞書YAMLの廃止と移行
旧来の `辞書.yaml` は廃止し、すべてシンボル付きのDBレコードとして管理する。

### 3.1 移行ルール
*   旧YAMLのキー → シンボル（記号）
*   旧YAMLの値 → `default_value` (JSON形式)
*   **構造化データの扱い**: JSON形式で文字列化してDBに格納する。

## 4. テンプレートの追加手順
1.  **JSON定義**: 追加するテンプレートの内容をJSONで定義する。
2.  **シンボル発行**: Symbol_Agentに申請し、テンプレートIDとなるシンボル（Group B: 設定・閾値カテゴリ）の発行を受ける。
3.  **登録**: 発行されたシンボルをキーとしてDBに登録する。

## 5. ユーザー定義テンプレート
*   ユーザーが作成したテンプレートは、別テーブル `user_templates` で管理する（`symbols` テーブルには混入させない）。
*   ただし、システム標準テンプレートとして昇格する場合は、シンボルを発行して `symbols` テーブルへ移行する。
