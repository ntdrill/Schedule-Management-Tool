## 提案/ドラフト
### 1) 既存シンボルへの対応付け（no-op 想定）
以下の候補は既存シンボルと意味が重複するため、**新規発行せず既存参照**とする提案。

- `User_State` → `user_state_current`（現在状態オブジェクトとして参照）
- `Log_State()` → `merge_state_snapshot` + `update_state_from_sensor`（センサー/主観入力の統合記録）
- `Compare(Expected, Actual)` → `evaluate_task_effect`（一致スコア/詳細評価の算出）
