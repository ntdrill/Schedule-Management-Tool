# proposal_user_interaction

作成日: 2026/02/13  
担当: User_State_Agent

## 資料準拠（事実）
- 環境エントロピー増加は測定能力低下を通じてユーザー状態悪化に波及する。
- 社会的状態（接触頻度・孤独感・サポート感）はユーザー状態に影響する。
- expectedState / actualState / evaluationResult による前後比較で評価する。

## ユースケース（提案/ドラフト）

### UC-1 環境悪化 -> ユーザー状態低下
前提:
- 整理整頓低下、換気不良、騒音増加が同時発生。

相互作用フロー:
1. 環境状態が悪化。
2. 認知リソースが環境ノイズへ消費される。
3. 測定能力低下 -> 現状認識/計画/実行が崩れる。

期待される状態変化:
- user_measurement_capability 低下
- 作業開始可能状態の判定が false へ遷移

### UC-2 社会的孤立 -> 認知機能低下
前提:
- 最終接触時間が長期化、孤独感が高止まり。

相互作用フロー:
1. 社会的フィードバック不足が継続。
2. 判断の自己完結化が進む。
3. ユーザー状態の認知・遂行が低下。

期待される状態変化:
- 孤独由来の危篤リスク上昇
- リカバリー系タスク（接触・会話）優先度上昇

### UC-3 ユーザー介入 -> 環境回復 -> ユーザー回復
前提:
- 掃除・換気タスクを実行可能。

相互作用フロー:
1. ユーザーが環境介入タスクを実行。
2. 環境状態が改善。
3. 測定能力が回復。

期待される状態変化:
- environment 指標改善（清潔度/換気）
- user 指標改善（測定能力/実行安定性）
