# Proposal: Monitoring State Use Cases (Phase 1 Foundation)

## 概要
本提案は、Phase 1 (Foundation) における「測定状態 (Monitoring State)」の単一領域ユースケースを定義するものです。
v1 (MVP) における「測定モードの管理」「測定品質の維持」「認知リソースの管理」に加え、理論基盤に基づく「測定能力（メタ認知能力）」の評価と「主観・客観の統合監視」をカバーします。

## 1. 定数 (Constants) / 静的定義

### 1.1 測定セッションオブジェクト (Measurement Session)
測定モードは独立した予定オブジェクトとして管理される。

- **id**: UUID
- **type**: "measurement_session" (固定)
- **status**: "scheduled" | "in_progress" | "completed" | "skipped" | "interrupted"
- **timeFrame**:
  - `scheduledStart`: Date (予定開始時刻)
  - `scheduledEnd`: Date (予定終了時刻)
  - `actualStart`: Date (実際のON時刻)
  - `actualEnd`: Date (実際のOFF時刻)
- **metrics**:
  - `averageQualityScore`: 0.0-1.0
  - `maxFatigueLevel`: 0.0-1.0
  - `dropoutRisk`: 0.0-1.0
  - `discrepancyScore`: 0.0-1.0

### 1.2 監視変数 (Monitoring Variables)

#### 品質・状態
- **measurement_quality_score (CMQS)**: 0.0-1.0
  - 構成要素: $S_{noise}$ (S/N比), $R_{loss}$ (欠損率), $C_{device}$ (デバイス状態), $A_{context}$ (文脈適合度)
- **last_valid_measurement_timestamp**: Date
  - 最後に有効なデータが取得された時刻。継続性判定に使用。
- **device_connection_status**: Map<DeviceId, Status>

#### リソース・能力
- **measurement_fatigue_level**: 0.0-1.0
  - 測定行為そのものへの疲労・飽き。
- **cognitive_resource_level**: 0.0-1.0
  - ウィルパワー残量。低下すると測定能力も低下する。
- **user_measurement_capability**: 0.0-1.0
  - **重要**: ユーザーが自身を客観視できる能力（メタ認知）。
  - 低下するとタスク遂行が「決定論的」から「確率的」へ移行する。

#### 適応・メンタルヘルス
- **sensor_habituation_factor**: 0.0-1.0
  - センサー装着への順化度。初期の過敏反応を補正する。
- **subjective_objective_discrepancy**: 0.0-1.0
  - 主観と客観の乖離度。解離（Dissociation）の指標。
- **response_latency_to_feedback**: Milliseconds
  - システム介入への反応時間。精神運動制止やフリーズの検知用。

### 1.3 制御定数 (Control Constants)
- **MEASUREMENT_LIMIT_DAILY**: 8時間
- **FATIGUE_ALERT_THRESHOLD**: 0.7
- **DATA_GAP_TOLERANCE**: 600秒
- **DISCREPANCY_ALERT_THRESHOLD**: 0.6 (乖離警告閾値)
- **CAPABILITY_THRESHOLD_FOR_MONITORING**: 0.3 (測定能力維持の限界値)

## 2. 変換 (Transformations) / ユースケース

### UC-M01: 測定セッションの開始 (Start Measurement Session)
- **Input**: User toggles "ON"
- **Process**:
  - `measurement_session` 作成
  - センサーデータ購読開始
  - **UC-M05 (主観入力)** を即時トリガー
  - `sensor_habituation_factor` に基づくベースライン補正適用
- **Output**: `measurementMode` = true

### UC-M02: 測定セッションの終了 (End Measurement Session)
- **Input**: User toggles "OFF"
- **Process**:
  - `measurement_session` 完了処理
  - **UC-M05 (主観入力)** トリガー（振り返り）
  - 統計保存
  - 疲労回復プロセス開始
- **Output**: `measurementMode` = false

### UC-M03: 測定品質のモニタリング (Monitor Data Quality)
- **Input**: Sensor Data Stream
- **Process**:
  - 4要素 ($S_{noise}, R_{loss}, C_{device}, A_{context}$) から CMQS を算出
  - `last_valid_measurement_timestamp` 更新
  - `validate_measurement_continuity` 関数による継続性判定
  - `DATA_GAP_TOLERANCE` 超過で中断判定
- **Output**: Updated Quality Score

### UC-M04: 測定疲労と制限管理 (Manage Measurement Fatigue)
- **Input**: Time Tick
- **Process**:
  - 疲労蓄積計算（線形+入力コスト）
  - リミット超過時の警告・推奨
- **Output**: Fatigue Level Update

### UC-M05: 主観入力のトリガー (Trigger Subjective Input)
- **Input**: Event or Interval
- **Process**:
  - 状態入力UI提示
  - 入力結果を `UserState` として保存
  - **UC-M06** へ移行
- **Output**: User Input Data

### UC-M06: 主観と客観の乖離・反応検知 (Detect Discrepancy & Latency)
- **Input**: Subjective Input, Sensor Data, User Reaction Time
- **Process**:
  - **乖離検知**: 主観スコアと客観スコアのベクトル距離を計算。`DISCREPANCY_ALERT_THRESHOLD` 超過で警告。
  - **反応潜時評価**: 通知から反応までの時間 (`response_latency`) を計測。
    - 遅延 (> 2x Base): 精神運動制止の疑い
    - 過速 (< 0.5s): 形骸化の疑い
    - 反応なし: フリーズまたは回避
- **Output**: Discrepancy Alert, Mental Health Flags

### UC-M07: デバイス接続の管理 (Manage Device Connection)
- **Input**: Connectivity Event
- **Process**:
  - 接続マップ更新
  - 切断時の品質スコア低下処理と再接続誘導
- **Output**: Connection Status

### UC-M08: 測定能力の評価 (Evaluate Measurement Capability)
- **Input**: `cognitive_resource_level`, Environment Entropy, Biology Factors
- **Process**:
  - 環境・生理要因から `user_measurement_capability` を算出
  - 閾値 (`CAPABILITY_THRESHOLD_FOR_MONITORING`) と比較
  - **判定**:
    - High: 決定論的モード（通常運転）
    - Low: 確率的モード（リカバリー優先、複雑なタスク提示停止）
- **Output**: System Mode Update, Intervention Suggestion

## 3. 形式的記述への橋渡し (To Data_Model_Agent)

### 必要なシンボル候補
- `Measurement_Session`: Class
- `Calc_CMQS(...)`: Function
- `Validate_Continuity(...)`: Function
- `Calc_Discrepancy(Sub, Obj)`: Function
- `Eval_Response_Latency(Time)`: Function
- `Calc_Measurement_Capability(...)`: Function
- `Judge_System_Mode(Capability)`: Function
- `Sensor_Habituation`: Variable

## 4. 備考
- **他エージェント連携**:
  - 環境エントロピー (`Environment_State_Agent`) は `UC-M08` の重要入力となる。
  - `User_State_Agent` とは乖離検知で密に連携する。
