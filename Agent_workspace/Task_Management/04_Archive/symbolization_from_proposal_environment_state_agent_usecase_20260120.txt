## 提案/ドラフト
### 1) 既存シンボルへの対応付け（no-op 想定）
以下の候補は既存シンボルと意味が重複するため、**新規発行せず既存参照**とする提案。

- `Exponential/Linear/Sigmoid Decay` → `decay_rate_air_quality` / `accumulation_rate_dust` 等の既存係数で代替
- `CleaningMethod` → `cleaning_method_selection` で対応
- `Entropy/Negentropy` → `calc_room_entropy` / `calc_negentropy` / `room_entropy_s` / `room_negentropy_j`

### 2) 新規シンボル提案（不足分）
#### Group C: 動的状態変数（Environment State フィールド）
- **name**: `mold_risk`
  - **description**: カビ発生リスク（0.0-1.0）
  - **value_type**: float
- **name**: `dust_accumulation`
  - **description**: 埃の蓄積度（0.0-1.0）
  - **value_type**: float
- **name**: `kitchen_grime`
  - **description**: キッチン汚れ度（0.0-1.0）
  - **value_type**: float
- **name**: `air_quality_internal`
  - **description**: 室内空気質（CO2等の総合指標）
  - **value_type**: float
- **name**: `bath_cleanliness`
  - **description**: 風呂場の清潔度（0.0-1.0）
  - **value_type**: float
- **name**: `room_clutter`
  - **description**: 部屋の散らかり度（人を呼べないレベル判定に使用）
  - **value_type**: float

#### Group C: 学習・評価用の状態変数
- **name**: `efficiency_gap`
  - **description**: 期待減少量と実績減少量の乖離（Actual - Expected）
  - **value_type**: float
- **name**: `cleaning_skill_level`
  - **description**: 掃除熟練度（例: 風呂掃除熟練度）
  - **value_type**: float

#### Group E: 変換・関数
- **name**: `calc_efficiency_gap`
  - **description**: 期待値と実績値からEfficiency Gapを算出する関数
  - **value_type**: float
- **name**: `update_cleaning_skill_level`
  - **description**: Efficiency Gapを入力し、熟練度パラメータを更新する関数
  - **value_type**: float
- **name**: `calc_environment_pl_report`
  - **description**: 期間内のネゲントロピーと消費エネルギーを集計しP/L指標を算出する関数
  - **value_type**: json
