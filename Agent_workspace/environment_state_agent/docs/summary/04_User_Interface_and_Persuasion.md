# ユーザーインターフェースと説得 (UI & Persuasion)

## 1. 概要
計算された「冷徹な最適解」を、生身の人間に行動させるためのインターフェース設計です。
ユーザーの「現在性バイアス（面倒だから後にしよう）」を打破し、行動変容を促すための「説得（Persuasion）」機能を実装します。

## 2. 説得のメカニズム

### 2.1 未来コストの可視化 (Projected Cost Visualization)
人間は「現在のコスト」を過大評価し、「未来の損失」を過小評価する傾向があります。
システムは `ProjectedCostPoint` データを用いて、未来のコスト推移を可視化します。

*   **指数関数的グラフ**:
    *   「今やれば5分（コスト小）」
    *   「来週やると3時間（コスト大）」
    *   この急激な右肩上がりのカーブを提示することで、恐怖感と危機感を喚起し、「今やるのが一番楽だ」と合理的に理解させます。

### 2.2 正当化メッセージ (Justification)
タスクを先送りする場合、ユーザーは罪悪感を感じることがあります。
システムは却下されたタスクに対して「正当化の理由」を付与します。

*   `LowROI`: 「まだ汚れが溜まっていないので、今やるのは非効率です。（戦略的待機）」
*   `ResourceShortage`: 「今は体力が足りません。カビ対策を優先するため、散らかりは無視しましょう。（優先順位）」

---

## 3. 環境状態フェーズの提案

統合スケジューリングツール向けに、環境の状態を5つのフェーズとして定義し、ユーザー状態に合わせて提供します。

| フェーズ名 | 定義・特徴 | スケジューリング用途 |
| :--- | :--- | :--- |
| **1. ゼロ・フリクション**<br>(Zero-Friction) | ノイズとなるオブジェクトが排除され、あらゆる行動への「起動コスト」が最小化された状態。 | **標準状態**の維持。<br>朝一番やタスク間のインターバル。 |
| **2. コグニティブ・クリアランス**<br>(Cognitive Clearance) | 空気質（CO2）と視覚ノイズが厳密に制御され、脳負荷が極小化された状態。 | **作業開始可能状態**とのペアリング。<br>Deep Work（集中作業）時。 |
| **3. 制御された拡散**<br>(Controlled Diffusion) | 作業に必要な道具が展開されている状態。散らかりとは区別される「準安定状態」。 | **作業中**。<br>この状態を「散らかり」と誤検知して掃除させないよう保護する。 |
| **4. 蓄積飽和**<br>(Saturation) | 線形な汚れが、掃除の「規模の経済」が成立するレベルまで蓄積した状態。 | **休息時**や週末。<br>掃除の「収穫期」として一括処理タスクをスケジュールする。 |
| **5. エントロピック・ハザード**<br>(Entropic Hazard) | 放置すると不可逆的悪化を招く危険状態（カビ等）。 | **緊急アラート**。<br>ユーザー状態に関わらず、強制的に介入タスクをねじ込む。 |

## 4. UIデータ構造

`PersuasiveAdapter` を通じて、以下の構造でフロントエンドへデータが渡されます。

```json
{
  "suggested_tasks": [
    {
      "task_id": "task_MoldRisk",
      "title": "MoldRiskへの介入",
      "urgency_score": 0.9,
      "persuasion_message": "警告: リスクが指数関数的に増大しています...",
      "projected_cost_series": [
        {"time_offset": 0, "predicted_action_cost": 10},
        {"time_offset": 1, "predicted_action_cost": 15},
        {"time_offset": 5, "predicted_action_cost": 150} // 爆発的増加
      ]
    }
  ],
  "postponed_tasks": [
    {
      "task_id": "rej_Clutter",
      "reason": "ResourceShortage",
      "justification_message": "今はリソースが不足しています..."
    }
  ]
}
```
