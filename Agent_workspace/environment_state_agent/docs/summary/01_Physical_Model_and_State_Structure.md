# 環境状態の物理モデルと状態構造

## 1. 概要
環境状態エージェントは、室内環境を単なるタスクリストではなく、物理法則に従って時間変化する「動的な系」としてモデル化します。
本ドキュメントでは、実装されている状態変数の定義と、議論により提案された拡張モデルについて記述します。

## 2. 実装済みモデル：崩壊ダイナミクス (Environment Dynamics)

`environment_dynamics.py` に実装されている環境変数は、それぞれ固有の「崩壊関数（Decay Dynamics）」を持ちます。
これにより、「放置した場合にどのように悪化するか」を予測します。

### 2.1 状態変数の定義
各変数は `0.0` (最良/秩序) から `1.0` (最悪/無秩序) の範囲で正規化されています。

| 変数名 | 日本語 | 崩壊モデル | 特性 | 最適戦略 |
| :--- | :--- | :--- | :--- | :--- |
| **DustAccumulation** | 埃の蓄積 | **Linear** (線形) | 時間と共に一定ペースで蓄積する。 | **規模の経済**<br>頻繁な掃除はコスト高。ある程度溜めてから一括処理するのが効率的。 |
| **MoldRisk** | カビ発生リスク | **Exponential** (指数) | 初期は緩やかだが、ある点を超えると爆発的に悪化する。<br>放置コストが無限大に発散する特性を持つ。 | **即時介入**<br>コストが高くても最優先でリソースを割り当て、芽を摘む必要がある。 |
| **AirQuality** | 空気質 (CO2等) | **Sigmoid** (S字) | ある程度までは耐えるが、閾値を超えると急激に環境が悪化・飽和する。 | **閾値制御**<br>悪化する直前（変曲点）での介入が最適。 |
| **Clutter** | 散らかり | **Linear** (線形) | 時間と共に一定ペースで増加する。<br>実害は埃よりも低い場合が多い。 | **戦略的放置**<br>リソース不足時は、合理的に切り捨て（先送り）が正当化される。 |

### 2.2 パラメータ定義
- **rate_coefficient**: 悪化の速度係数。
- **entropy_weight**: 心理的・機能的な不快感の重み付け。物理的な量が同じでも、ユーザーにとっての「嫌さ」が異なることを表現。
- **base_intervention_cost**: 介入の固定コスト（着手の手間）。
- **unit_intervention_cost**: 介入の変動コスト（汚れの量に応じた手間）。

## 3. 拡張モデル案：三位一体データモデル (Trinity Data Model)

議論により、現在の「バランスシート（状態スナップショット）」型から、「損益計算書（プロセス）」型への移行が提案されています。

### 3.1 Variable (状態変数の拡張)
単なる汚れの量だけでなく、**物理的性質 (ResistanceType)** を持ちます。
- **Lipid**: 脂質汚れ（水に強い、アルカリに弱い）
- **Particulate**: 粒子汚れ（飛散しやすい、吸着に弱い）
- **Adhesive**: 固着汚れ（物理的剪断力が必要）
- **Biological**: 生物汚染（殺菌が必要）

### 3.2 CleaningMethod (清掃メソッドの新設)
掃除手段を単なるラベルではなく、物理パラメータの集合体として定義します。
- **MechanismType**: 作用機序（物理的・化学的・熱的）
- **Activation Energy**: **起動コスト**（掃除機を出す、バケツに水を汲む等の初期障壁）
- **Psychological Wear**: **心理的摩耗**（不快感やストレスによるHP減少係数）
- **Energy Cost**: 消費エネルギー（代謝カロリー・電力）
- **Compatibility**: 汚れの性質との適合係数

### 3.3 InterventionTransaction (介入履歴の新設)
介入の事実を時系列ログとして記録し、学習データとします。
- **Expected Delta**: 理論上の期待エントロピー減少量。
- **Actual Delta**: 実際に観測された減少量。
- **Efficiency Gap**: 上記の乖離。ユーザーの熟練度（プラス乖離）や道具の劣化（マイナス乖離）を検知するために使用。
