# ネゲントロピー計算ロジック

## 1. 概要
本システムにおける「ネゲントロピー」は、抽象的な概念ではなく、掃除という物理的作業を通じて計算可能な定量指標として定義されます。
これにより、掃除の成果を「どれだけ綺麗になったか」という主観ではなく、「どれだけエントロピーを減少させたか」という物理量として評価します。

## 2. 機能的エントロピー (Functional Entropy)

部屋の乱雑さを、それを片付けるために必要な「仕事量（時間）」として定義します。

### 2.1 定義
**$S_{room}$ (部屋のエントロピー)**
基準となる掃除屋（ユーザー自身または標準モデル）が、現在の部屋の状態から完全に片付いた基準状態にするために必要な**期待掃除時間**。

### 2.2 計算式
$$
S_{room} = \sum_{\alpha} \sum_{i} (\tau_i \cdot n_{\alpha,i})
$$

- $\alpha$: エリア (Area A, B, ...)
- $i$: タスク種別 (皿洗い, 服の片付け, ゴミ拾い...)
- $\tau_i$: タスク $i$ の単位処理時間 (分/個)
- $n_{\alpha,i}$: エリア $\alpha$ におけるタスク $i$ の残存量 (個数)

**意味**:
この値（分）は、部屋が抱えている「未処理の仕事量（負債）」を表します。
- $S_{room} = 0$: 完全な秩序状態。
- $S_{room}$ が増大: 部屋が散らかっている状態。

---

## 3. 環境ネゲントロピー (Environment Negentropy)

介入（掃除）によって生み出された「秩序の量」を定義します。

### 3.1 定義
**$J$ (ネゲントロピー)**
ある期間（または1回の介入）において減少したエントロピーの量。

### 3.2 計算式
$$
J = -\Delta S_{room} = S_{before} - S_{after}
$$

**解釈**:
ユーザーがシステム（部屋）に対して外部から仕事を行い、エントロピーを系外へ排出した成果です。
これをユーザーの「スコア」や「貢献度」として扱います。

---

## 4. 熱力学的リンク (Thermodynamic Link)

「部屋が綺麗になること」と「エネルギー消費」の関係を、熱力学第二法則とリンクさせます。

### 4.1 エネルギー収支
掃除を行うには、エネルギー（代謝エネルギーまたは電力）が必要です。
このエネルギー消費は、最終的に「熱」として環境（部屋の空気や外界）に捨てられます。

### 4.2 熱エントロピーの増大
消費されたエネルギー $Q$ によって、環境の熱エントロピー $S_{env}$ は増大します。

$$
\Delta S_{env} \approx \frac{Q}{T}
$$
($T$: 室温)

### 4.3 トレードオフの評価
システムは以下の不等式を評価軸とします。

$$
\Delta S_{total} = \Delta S_{env} + \Delta S_{room} \ge 0
$$

- **$\Delta S_{room} < 0$**: 部屋のエントロピー減少（秩序化）。
- **$\Delta S_{env} > 0$**: 熱エントロピー増大（排熱）。

ユーザーは「熱エントロピーの増大」という代償を支払って、「部屋のネゲントロピー」を購入していると解釈できます。
高効率な掃除とは、**最小の $Q$（労力・電力）で最大の $J$（片付け効果）を得ること**と同義になります。
