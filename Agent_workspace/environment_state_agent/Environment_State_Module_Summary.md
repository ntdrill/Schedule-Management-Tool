# Environment State Module Architecture Summary

## 1. 概要
本モジュールは、室内環境を「散逸構造」として定義し、熱力学第二法則に基づくエントロピー増大（状態悪化）と、それに対する介入（仕事）の最適化を行う自律意思決定エンジンである。

## 2. コアコンポーネント

### 2.1. Environment Dynamics (物理レイヤー)
対象の物理的特性に応じた崩壊モデルを定義する。

*   **Linear Decay (線形崩壊)**
    *   対象: `DustAccumulation` (埃), `Clutter` (散らかり)
    *   特性: 時間経過と共に一定ペースで悪化。
    *   戦略: **規模の経済**。溜めてから一括処理する方が効率的。
*   **Exponential Decay (指数崩壊)**
    *   対象: `MoldRisk` (カビ)
    *   特性: 初期は緩やかだが、ある時点を超えると爆発的に悪化。
    *   戦略: **早期介入**。微小な兆候の段階で潰さなければ、将来コストが許容不能なレベルに達する。
*   **Sigmoid Decay (S字崩壊)**
    *   対象: `AirQuality` (空気質)
    *   特性: 閾値付近で急激に相転移（悪化）し、飽和する。
    *   戦略: **閾値制御**。急激な悪化が始まる直前（変曲点手前）での介入が最適。

### 2.2. Cost Dynamics (経済レイヤー)
介入にかかるコスト構造を定義する。

*   **Linear Cost**: 汚れの量に比例、または固定コスト支配型（掃除機など）。
*   **Exponential Cost**: 悪化度に応じて除去難易度が指数的に跳ね上がる（カビ除去など）。

### 2.3. Resource Arbitration (調停レイヤー)
「リソース制約付きナップサック問題」として、複数の介入要求を調停する。

*   **評価関数**: 限界効用（Marginal Utility） = $\frac{d(\text{Penalty})}{dt}$
    *   単純な「現在の汚れ具合」ではなく、「今介入しないと将来どれだけ損をするか（機会費用）」を基準とする。
*   **挙動**:
    *   致命的な指数的リスク（Mold）を最優先で確保。
    *   残余リソース（隙間時間）に対し、コストパフォーマンスの良いタスク（Air）をパズルのように埋め込む。
    *   損失は生じているが緊急性の低い線形タスク（Clutter）は、リソース不足時は合理的に棄却（先送り）する。

## 3. 結論
本システムは、人間の直感（バイアス）を排し、数理モデルに基づく「冷徹な合理的判断」を出力することに成功している。特に、「いつ掃除すべきか」という問いに対し、対象の物理特性のみから「溜める」と「即断」という真逆の戦略を自律的に導出した点は、本設計の妥当性を証明している。
