ネゲントロピーは、ざっくり言うと

> **「同じ分散を持つガウス分布のエントロピー − 実際の分布のエントロピー」**

で定義される“**ガウス分布からどれだけ離れているか**”の指標です。

---

## 1. エントロピーの復習

### 離散の場合（確率変数が取りうる値が有限個）

確率変数 (X) が値 (x_i) を確率 (p_i = P(X = x_i)) でとるとき、
エントロピー (H(X)) は

[
H(X) = -\sum_i p_i \log p_i
]

* (\log) の底が 2 なら単位は「ビット」
* (\log) の底が (e) なら単位は「ナット」

になります。

### 連続の場合（確率密度 (f(x)) を持つ）

確率変数 (X) の確率密度を (f(x)) とすると、**微分エントロピー** (h(X)) は

[
h(X) = -\int_{-\infty}^{\infty} f(x),\log f(x),dx
]

です（こちらも (\log) の底で単位が変わります）。

---

## 2. ネゲントロピーの定義

### (1) 一般的な連続分布の場合

平均 (\mu)、分散 (\sigma^2) を持つ連続確率変数 (X) を考えます。
この (X) と**同じ平均・分散**を持つガウス分布（正規分布）を (X_{\text{Gauss}}) と書くと、

[
J(X) = h(X_{\text{Gauss}}) - h(X)
]

を **ネゲントロピー (negentropy)** と呼びます。

一変量正規分布 (X_{\text{Gauss}} \sim \mathcal N(\mu, \sigma^2)) の微分エントロピーは

[
h(X_{\text{Gauss}}) = \frac{1}{2}\log\big(2\pi e \sigma^2\big)
]

なので、ネゲントロピーは

[
J(X) = \frac{1}{2}\log\big(2\pi e \sigma^2\big) - h(X)
]

となります。

* (J(X) \ge 0)
* (X) が本当にガウス分布のときだけ (J(X) = 0)
* ガウス分布から離れるほど (J(X)) が大きくなる

という性質があります。

---

### (2) 離散分布の場合（よくある定義）

離散的な (n) 通りの値を取る確率変数 (X) の場合、
エントロピーの **最大値** は各値が等確率のときで

[
H_{\max} = \log n
]

です。
このときの **ネゲントロピー** を

[
J(X) = H_{\max} - H(X) = \log n - \left(-\sum_i p_i \log p_i\right)
]

のように定義することがあります。

---

## 3. 実際に計算するときの手順

### 3-1. 理論分布が分かっているとき（解析的に計算）

1. **分布の密度 (f(x))** を書き下ろす。
2. 微分エントロピーを計算する：
   [
   h(X) = -\int f(x),\log f(x),dx
   ]
3. (X) の分散 (\sigma^2) を計算する。
4. 同じ (\sigma^2) のガウス分布のエントロピーを計算する：
   [
   h(X_{\text{Gauss}}) = \frac{1}{2}\log(2\pi e \sigma^2)
   ]
5. 差を取る：
   [
   J(X) = h(X_{\text{Gauss}}) - h(X)
   ]

※ 解析的に積分ができない分布も多いので、その場合は次の「標本からの近似」を使います。

---

### 3-2. データ（サンプル）から近似計算する場合

実際のデータ (x_1, x_2, \dots, x_N) からネゲントロピーを求めたいとき、代表的なやり方は次のような流れです（ICAなどでよく使われます）。

#### 手順の流れ

1. **平均・分散の推定**
   [
   \hat\mu = \frac{1}{N}\sum_{k=1}^N x_k,\quad
   \hat\sigma^2 = \frac{1}{N}\sum_{k=1}^N (x_k - \hat\mu)^2
   ]

2. **標準化**
   [
   y_k = \frac{x_k - \hat\mu}{\hat\sigma}
   ]
   こうすると、(y) は平均 0、分散 1 になります。

3. **(h(Y)) を近似計算**
   いくつか方法があります：

   * **ヒストグラムやカーネル密度推定**で (f_Y(y)) を推定し、
     [
     h(Y) \approx -\sum_{\text{bin}} \hat f_Y(y),\log \hat f_Y(y),\Delta y
     ]
   * あるいは、ICA などでよく使う**近似式**：

     * 例：
       [
       J(Y) \approx \frac{1}{12}\big(E[Y^3]\big)^2 + \frac{1}{48}\big(\kappa(Y)\big)^2
       ]
       ここで (\kappa(Y)) は尖度（kurtosis）です。
     * あるいは
       [
       J(Y) \approx \big( E[G(Y)] - E[G(V)] \big)^2
       ]
       （(V) は標準正規、(G) は適当な非線形関数）
       といった経験的な近似式も使われます。

4. **ガウスのエントロピーとの差を取る**
   標準化しているので、対応するガウス分布は (\mathcal N(0,1)) で
   [
   h(\mathcal N(0,1)) = \frac{1}{2}\log(2\pi e)
   ]
   したがって
   [
   J(Y) = \frac{1}{2}\log(2\pi e) - h(Y)
   ]
   これが求めたいネゲントロピーの近似になります。
   元の (X) についても、同じ値になります（線形なスケーリングではネゲントロピーは変わりません）。

---

## 4. まとめ

* **連続分布のネゲントロピー**

  * (J(X) = h(\text{同じ分散のガウス}) - h(X))
  * 一変量なら (J(X) = \frac{1}{2}\log(2\pi e \sigma^2) - h(X))
* **離散分布のネゲントロピー**

  * (J(X) = \log n - H(X))（定義の一例）
* 実際のデータから計算するときは、

  1. 平均・分散を求めて標準化
  2. 標準化したデータのエントロピーを推定
  3. 標準正規のエントロピーとの差を取る
     という手順で近似的に求めます。

もし「具体的な分布（例：一様分布、指数分布など）で実際に計算してみたい」などあれば、その例でも計算を一緒にやってみましょう。

一番ポイントだけ先に言うと、

> ネゲントロピー (J(X)=h(\text{Gauss})-h(X)) は
> **「同じ広がり（分散）を持つガウス分布と比べて、どれだけ“エントロピーが少ない＝秩序や構造があるか」**
> を測っている量です。

その「比べ方」が、実は**KLダイバージェンスそのもの**になっていて、
「ガウス分布からの距離」を測る *自然な指標* になっている、というのが「なぜそう定義してよいか」の核心です。

---

## 1. まず前提：ガウス分布は「同じ分散なら一番ランダム」

情報理論の重要な定理に

> **平均と分散が同じクラスの分布の中で、エントロピーが最大になるのはガウス分布だけ**

というものがあります。

つまり

[
h(X)\ \le\ h(X_{\text{Gauss}})
]

で、等号になるのは (X) が本当にガウス分布のときだけ、という性質です。

ここからわかること：

* 同じ「ばらつき（分散）」を持つなら

  * ガウス分布は **「一番ごちゃごちゃに散らばっていて予測しにくい」＝一番エントロピーが大きい**
  * それ以外の分布はどれも **ガウスよりエントロピーが小さい**（＝どこかにパターン・偏り・構造がある）

だから

[
h(X_{\text{Gauss}})-h(X)\ \ge\ 0
]

で、しかも 0 になるのは「ガウスそのもののときだけ」です。

この**非負で 0 だけ特別**という形は、「距離」や「散らばりの差」を測る量としてとても都合が良いですよね。

---

## 2. 「最大値 − 実際の値」という発想そのものが“どれだけ特別か”を測る

エントロピーに限らず、こういう考え方はよく出てきます：

* ある制約（ここでは「分散が一定」）のもとで
* ある量（ここではエントロピー）には **理論上の最大値** がある
* **「最大値 − 実際の値」** を取ると

  * その制約のもとで「どれだけ特別に“秩序立っている”か・構造があるか」を測れる

離散分布の場合も同じで、

* (n) 通りを取りうる確率変数のエントロピー最大値は (\log n)（一様分布）
* ネゲントロピーを (J(X) = \log n - H(X)) と置くと

  * 一様分布 → (J = 0)（一番ランダム）
  * 偏りが強いほど → (H) が小さくなり、(J) が大きくなる（秩序がある）

この「**最大エントロピーからどれだけ減っているか**」という定義は、「ランダムさからどれだけ外れているか」を定量化する、とても自然なやり方なんです。

連続分布では、「最大エントロピー分布」が **“同じ分散を持つガウス分布”** なので、
そこで最大値 (h(X_{\text{Gauss}})) を基準にして

[
J(X) = h(X_{\text{Gauss}}) - h(X)
]

とするわけです。

---

## 3. 実はこれは KL ダイバージェンスそのもの

もう一歩踏み込むと、
このネゲントロピー (J(X)) は、**ガウス分布との KL ダイバージェンス**になっています。

KL ダイバージェンス（Kullback–Leibler divergence）は

[
D_{\mathrm{KL}}(f|g)
= \int f(x),\log\frac{f(x)}{g(x)},dx
]

という「分布 (f) と (g) の違い」を測る標準的な指標です（非対称な距離みたいなもの）。

ここで

* (f(x))：実際の分布 (X) の密度
* (g(x))：同じ平均・分散を持つガウス分布 (X_{\text{Gauss}}) の密度

とすると、計算してみると

[
D_{\mathrm{KL}}(f|g)
= h(X_{\text{Gauss}}) - h(X)
= J(X)
]

となります（同じ分散を共有しているので、途中の余計な項がきれいに消えます）。

つまりネゲントロピーは

> 「実際の分布 (X) が、同じ分散のガウス分布 (X_{\text{Gauss}}) からどれだけ離れているか」
> を表す **KL ダイバージェンスそのもの**

なんです。

KL ダイバージェンスには

* 常に (D_{\mathrm{KL}}(f|g) \ge 0)
* (f = g) のときだけ 0
* 連続的に変化する
* 情報理論・統計で「分布の違い」を測る標準的指標

という性質があるので、
それと**完全に同じもの**を使っているというのは、かなり自然で筋の通った選び方だと分かります。

---

## 4. 直感的なイメージ

平均 0、分散 1 にそろえた2つの分布を考えます：

1. **キレイなベル型（標準正規）**

   * どの辺りに値が来るか、そこそこバラバラ
   * 「どこに出るかだいたい同じくらいあり得る」ので、エントロピーが最大級

2. **両端にとがった二山分布**（例：(\pm 3) のあたりに集中）

   * 値が極端なところに集まっている
   * 見かけ上の「ばらつき」（分散）は同じでも、実は

     * 「真ん中付近にはほとんど来ない」
     * 「大きくプラスかマイナスのどちらかだ」
   * つまり、**情報（構造・偏り）が増えている** → エントロピーは小さくなる

このとき、ネゲントロピー (J) は

* ガウス分布：(J = 0)
* 二山分布：(J > 0)（**ガウスからのズレ＝構造の多さ**）

を与えます。

---

## 5. まとめると…

「なぜ (J(X) = h(\text{Gauss}) - h(X)) で“ガウスからのズレ（ネゲントロピー）”が測れるのか？」という問いへの答えは：

1. **同じ平均・分散を持つ分布の中で、ガウス分布はエントロピー最大**
   → だから「最大エントロピー − 実際のエントロピー」は
   「**どれだけランダムさが減っているか＝どれだけ構造があるか**」を測る自然な量。

2. その差 (h(\text{Gauss}) - h(X)) は、
   実は **ガウス分布との KL ダイバージェンスそのもの**であり、
   「ガウスからの情報論的な距離」を表す標準的な指標になっている。

3. よってネゲントロピーは

   * 常に 0 以上
   * ガウスのときだけ 0
   * ガウスから離れるほど大きくなる
     という“理想的な「非ガウス性の度合い」”になっている。

だから、「この定義で『ガウスからどれだけ遠いか』がちゃんと測れている」と考える、というわけです。

## 1. 発想：エントロピー＝「基準掃除屋がゼロにするまでの最小時間」

本物の熱力学的エントロピーを部屋で求めるのはほぼ不可能なので、
ここでは**「機能的なエントロピー」**として次のように定義します：

> ある状態の部屋を、基準となる掃除屋が
> 「完全に片付いた基準状態」にするのに必要な**期待掃除時間**を
> その部屋状態のエントロピー (S) とみなす。

この定義のいいところ：

* すべて片付いた状態では
  → 必要時間 0 → (S = 0)
* 物や汚れが増えるほど
  → 必要時間が増える → (S) が大きくなる
* 掃除をすると
  → 必要時間が減る → (S) が減る（＝局所的なエントロピー低下）

つまり
**「未処理掃除タスクの総量（掃除時間）」をエントロピーとして扱う**わけです。

---

## 2. 掃除屋の処理能力から「1個あたり時間」を求める

ユーザ（掃除屋）の処理能力から「1アイテムあたり平均何分かかるか」を出します。

あなたの例だと：

* 皿洗い：20個 20分 → 1皿あたり
  [
  \tau_{\text{皿}} = \frac{20}{20} = 1\ \text{分/個}
  ]
* 洗濯物：40個 20分 → 1枚あたり
  [
  \tau_{\text{洗濯物}} = \frac{20}{40} = 0.5\ \text{分/個}
  ]
* トイレ掃除：20箇所 13分 → 1箇所あたり
  [
  \tau_{\text{トイレ}} = \frac{13}{20} \approx 0.65\ \text{分/箇所}
  ]
* ゴミ拾い：15個 4分 → 1個あたり
  [
  \tau_{\text{ゴミ}} = \frac{4}{15} \approx 0.27\ \text{分/個}
  ]
* 領収書類収集：15枚 2分 → 1枚あたり
  [
  \tau_{\text{領収書}} = \frac{2}{15} \approx 0.13\ \text{分/枚}
  ]

同様に、家具・設備も「1つ掃除するのに何分かかるか」を決めればいいです。

* 例えば a, b, c, d の4つの家具をウェットシート＋ドライシート＋アルカリスプレーで掃除して20分かかったなら
  「1家具あたり 5分」とみなせます：
  [
  \tau_{\text{家具}} = \frac{20}{4} = 5\ \text{分/個}
  ]
  （実際は種類ごとに違う係数を持たせてもOK）

こうして、「タスク種別ごとの単位時間 (\tau_i)」を用意します。

## 3. 状態表現：エリア×タスク種別でカウントする

部屋を A〜P のエリアに分割し、
タスク種別（皿、服、ごみ、領収書、トイレ、家具 a〜x …）ごとに**個数をカウント**します。

* エリア (\alpha)（A〜P）
* タスク種別 (i)（皿、洗濯物、ゴミ、トイレ、領収書、家具a…x）

とすると、そのエリアにある「未処理アイテム数」を

[
n_{\alpha,i}
]

とおきます。
例：エリア A に皿が 10 枚、ゴミが 3 個なら

* (n_{\mathrm{A},\text{皿}} = 10)
* (n_{\mathrm{A},\text{ゴミ}} = 3)

みたいな感じ。

## 4. 局所エントロピーと全体エントロピーの定義

### 4.1 エリアごとの局所エントロピー

エリア (\alpha) のエントロピーを

[
S_\alpha = \sum_i \tau_i \cdot n_{\alpha,i}
]

とします。
（(\tau_i) はタスク種別 (i) の「1個あたり掃除時間」）

* 単位は「分」
* そのエリアだけを完全に片付けるのに基準掃除屋が必要とする時間に対応

### 4.2 部屋全体のエントロピー

部屋全体はエリアの和なので

[
S_{\text{room}} = \sum_\alpha S_\alpha
= \sum_\alpha \sum_i \tau_i \cdot n_{\alpha,i}
]

これが「**部屋のエントロピー**」です。

* すべて片付いていれば → 全ての (n_{\alpha,i}=0) → (S_{\text{room}}=0)
* 汚れや物が増えるほど (n_{\alpha,i}) が増え → (S_{\text{room}}) が大きくなる

---

## 5. 掃除による「局所的なエントロピー低下」とネゲントロピー

掃除すると、あるエリア (\alpha)・タスク種別 (i) の数が減ります。

[
n_{\alpha,i} \to n_{\alpha,i}' = n_{\alpha,i} - \Delta n_{\alpha,i}
]

とすると、エリア (\alpha) のエントロピー変化は

[
\Delta S_\alpha
= S_\alpha' - S_\alpha
= \sum_i \tau_i (n_{\alpha,i} - \Delta n_{\alpha,i}) - \sum_i \tau_i n_{\alpha,i}
= -\sum_i \tau_i \Delta n_{\alpha,i}
]

掃除でアイテム数が減っているので (\Delta n_{\alpha,i} \ge 0) ですから

* (\Delta S_\alpha \le 0)（エントロピーは減る）

この**「減った分の大きさ」**をその掃除ステップで生み出された**ネゲントロピー**として定義できます：

[
J_\alpha = -\Delta S_\alpha = \sum_i \tau_i \Delta n_{\alpha,i}
]

* (J_\alpha \ge 0)
* 値が大きいほど、その掃除行動が「大きな秩序の回復」を生んだと言える

部屋全体では

[
J_{\text{step}} = \sum_\alpha J_\alpha = -\Delta S_{\text{room}}
]

さらに「ネゲントロピー生成速度」として

[
\dot J = \frac{J_{\text{step}}}{\Delta t}
]

（＝1分あたりどれだけエントロピーを減らしたか）
を使ってもいいです。

## 6. 清掃方法（ウェットシート / スプレーなど）をどう組み込むか

清掃方法ごとに処理能力が変わるなら、
**「タスク種別 × 清掃方法」ごとに単位時間を設定**するとモデルが細かくなります。

* タスク種別 (i)（皿、ごみ、トイレ…）
* 清掃方法 (m)（ウェットシート、ドライシート、アルカリ、アルコール、メラミン、雑巾、水気取り…）

## 1. 部屋エントロピー (S_{\text{room}}) を定義する

まず、前に話した「掃除時間ベースのエントロピー」をキッチリ式にします。

### 1-1. 1個あたりの掃除時間（処理能力）

あなたがくれた実測値から、1個あたりの平均時間を出します：

* 皿洗い：20個 20分
  [
  \tau_{\text{皿}} = \frac{20}{20} = 1.0\ \text{分/枚}
  ]
* 洗濯物：40個 20分
  [
  \tau_{\text{洗濯}} = \frac{20}{40} = 0.5\ \text{分/枚}
  ]
* トイレ掃除：20箇所 13分
  [
  \tau_{\text{トイレ}} = \frac{13}{20} \approx 0.65\ \text{分/箇所}
  ]
* 部屋のゴミ拾い：15個 4分
  [
  \tau_{\text{ゴミ}} = \frac{4}{15} \approx 0.27\ \text{分/個}
  ]
* 領収書類収集：15枚 2分
  [
  \tau_{\text{領収書}} = \frac{2}{15} \approx 0.13\ \text{分/枚}
  ]
* 家具 a,b,c,d の清掃：4個 20分
  [
  \tau_{\text{家具}} = \frac{20}{4} = 5.0\ \text{分/個}
  ]

これが「基準掃除屋の処理能力」です。

### 1-2. 部屋の状態をカウントで表す

今回はシンプルに「部屋全体をひとつのエリア」として、
初期状態をこんな感じに仮定します：

* 皿：20枚
* 洗濯物：40枚
* ゴミ：15個
* 領収書：15枚
* トイレ：1箇所が汚れている
* 汚れた家具：a,b,c,d の4つ

つまり個数：

[
\begin{aligned}
n_{\text{皿}} &= 20 \
n_{\text{洗濯}} &= 40 \
n_{\text{ゴミ}} &= 15 \
n_{\text{領収書}} &= 15 \
n_{\text{トイレ}} &= 1 \
n_{\text{家具}} &= 4
\end{aligned}
]

### 1-3. 部屋エントロピー (S_{\text{room}})

「その状態から全部片付けるのに必要な期待掃除時間」を

[
S_{\text{room}}
= \sum_i \tau_i,n_i
]

で定義します。
上の数字を全部入れると：

[
\begin{aligned}
S_{\text{room}}
&= 1.0\times 20

* 0.5\times 40
* 0.27\times 15
* 0.13\times 15
* 0.65\times 1
* 5.0\times 4 \
  &\approx 66.65\ \text{分}
  \end{aligned}
  ]

つまりこの部屋は、

> **「基準掃除屋が約 66.7 分かければ完全に片付く状態」**

という意味で、エントロピー (S_{\text{room}} \approx 66.7\ [\text{分}])
と表現できます。

（実は「タスク時間の合計」をそのまま式にしただけなので、
感覚的にもそのままですね）

---

## 2. 掃除によるネゲントロピー：(\Delta S_{\text{room}})

この状態から、あなたが一気に全部掃除したとします：

* 皿も洗う
* 洗濯物も全部処理
* ゴミも領収書もトイレも家具も全部きれい

最終状態ではすべての (n_i=0) なので

[
S_{\text{room}}^{\text{(after)}} = 0
]

よって変化量は

[
\Delta S_{\text{room}}
= S_{\text{room}}^{\text{(after)}} - S_{\text{room}}^{\text{(before)}}
= 0 - 66.65 = -66.65\ \text{分}
]

この「減った分」の大きさを

[
J_{\text{clean}} = -\Delta S_{\text{room}} = 66.65\ \text{分}
]

と定義すれば、これは

> **「この掃除でどれだけ“部屋の乱雑さを減らしたか”というネゲントロピー**

に相当します。

---

## 3. 掃除で消費されるエネルギーと、環境の熱エントロピー

次に、「本物の熱力学的エントロピー」に少し寄せるために、
掃除に使われるエネルギーと、それによる環境のエントロピー増大を見ます。

### 3-1. 掃除中の人間の出力をざっくり仮定

掃除中の人間の平均出力（追加の消費エネルギー）を
ざっくり **150 W** と仮定します（かなり軽めの肉体労働レベル）。

掃除時間はさっきの (S_{\text{room}}) と同じ 66.65分 ≒ 1.11時間。

エネルギー消費 (Q_{\text{human}}) は

[
Q_{\text{human}}
= P \times t
= 150\ \text{W} \times 66.65\ \text{分} \times 60\ \text{秒/分}
\approx 6.0\times 10^5\ \text{J}
]

（約 0.6 MJ）

### 3-2. 熱エントロピー増大 (\Delta S_{\text{env}})

このエネルギーは最終的にはほぼ全部「熱」として
部屋や外界にばらまかれると考えられます。

室温をざっくり (T = 300\ \text{K}) とすると、
環境の熱エントロピー増大は

[
\Delta S_{\text{env}}
\approx \frac{Q_{\text{human}}}{T}
\approx \frac{6.0\times 10^5}{300}
\approx 2.0\times 10^3\ \text{J/K}
]

くらいのオーダーになります。

ここで見えているのは：

* **部屋の「機能的エントロピー」**：
  (-\Delta S_{\text{room}} = 66.7\ \text{分}) だけ減少
* **環境の「熱的エントロピー」**：
  (\Delta S_{\text{env}} \approx 2.0\times 10^3\ \text{J/K}) だけ増加

という二重構造です。

---

## 4. 全体としてのバランス

ここで重要なのは、「何をエントロピーと呼ぶか」の違いです。

* (S_{\text{room}})：
  → 皿・服・ゴミ・家具などの**配置・汚れ状態**を
  「掃除時間」で測った**機能的エントロピー**

* (\Delta S_{\text{env}})：
  → 人間の代謝＋作業が出した熱で増える
  **純粋に熱力学的なエントロピー**

掃除というプロセスは

> * 部屋の構造的・意味的な乱雑さ（(S_{\text{room}})）を減らす
> * その代わりに外界の熱エントロピー（(\Delta S_{\text{env}})）を増やす

という形で、

* **局所的にはネゲントロピー（秩序）が生まれる**
* **全体（人＋部屋＋外界）ではエントロピーは増える**

という、まさに第二法則どおりの振る舞いをしています。

---

## 5. このモデルをどう発展させられるか

ここまでで最低限の「やってみた」は：

1. 部屋状態 → 未処理タスクの個数 (n_i) による
   機能的エントロピー (S_{\text{room}}) を定義
2. 掃除前後の差 (-\Delta S_{\text{room}}) を
   ネゲントロピー (J_{\text{clean}}) として評価
3. 掃除に使ったエネルギーから
   (\Delta S_{\text{env}} \approx Q/T) を見積もり、
   熱力学的エントロピーとの接点を作る

ここからさらにやろうと思えば：

* 掃除機・洗濯機などの**電気機器の消費電力**も足し込む
* 「1分の掃除時間あたり平均何 J のエネルギーを使っているか」で
  **機能的エントロピー（分）と熱エントロピー（J/K）を緩く対応づける**
* 部屋を A〜P のエリアに分けて
  (S_A, S_B, \dots) を定義し、どこが一番カオスかを可視化する

……みたいな方向に広げられます。

---

もしよければ次は、

* 「エリアAには皿〇枚、ゴミ〇個、家具〇個…」という
  **もう少し細かい例**をひとつ決めて、
* 各エリアごとの (S_\alpha) と
  一回の掃除での (\Delta S_\alpha)、(J_\alpha) を出してみる

こともできます。
そうすると「どのエリアでどれだけネゲントロピーを生んだか」がマップになります。
