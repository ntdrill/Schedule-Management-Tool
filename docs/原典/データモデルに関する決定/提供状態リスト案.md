# 提供状態リスト案（ドラフト）

本システムでは、ユーザーがゼロから状態を定義するのではなく、デベロッパー（専門家）が設計した「状態プリセット」を選択して使用する。以下は初期リリース時に提供すべき状態リストのドラフトである。

## 1. ユーザー状態 (User State)
ユーザーの生理的・心理的な準備モード。

| 状態名 | 定義・特徴 | 想定される活動 |
| :--- | :--- | :--- |
| **標準 (Standard)** | 起きている間のニュートラルな状態。過度な緊張も弛緩もない。 | 日常生活、移動、家事 |
| **作業開始可能 (Work Ready)** | 交感神経が優位になりつつも、安定した心拍・血圧にある状態。 | デスクワーク、学習、会議 |
| **集中 (Deep Focus)** | 高い覚醒レベルと低い外部反応性。フロー状態に近い。 | 創作活動、コーディング、執筆 |
| **休息 (Rest/Recovery)** | 副交感神経優位。筋緊張が解け、心拍数が低下している。 | 休憩、マインドフルネス、入浴 |
| **睡眠 (Sleep)** | 入眠および睡眠中の状態。 | 睡眠 |
| **覚醒準備 (Wake Up)** | 睡眠から覚醒へ移行する過渡期。体温上昇、コルチゾール分泌。 | 起床直後のルーチン |
| **想起: [イベント名]** | 特定の外部予定（会議、締切等）を意識・記憶している状態。 | （スケジュール上の予定に対応） |

## 2. 環境状態 (Environment State)
ユーザーの行動に対する場の物理的・情報的抵抗（フリクション）。

| 状態名 | 定義・特徴 | 熱力学的特性 |
| :--- | :--- | :--- |
| **ゼロ・フリクション** | ノイズとなるオブジェクトが排除され、あらゆる行動への起動コストが最小。 | 低エントロピー、高遷移ポテンシャル |
| **コグニティブ・クリアランス** | 空気質（CO2等）と視覚ノイズが厳密に制御され、脳負荷が極小。 | Sigmoid制御下、心理的摩耗なし |
| **制御された拡散** | 作業に必要な道具が展開されているが、秩序ある配置（散らかりではない）。 | 準安定状態、局所的ネゲントロピー |
| **蓄積飽和 (Saturation)** | 生活汚れが「まとめて掃除」に適したレベルまで蓄積した状態。 | 介入効率最大、掃除の収穫期 |
| **エントロピック・ハザード** | 不可逆的悪化のリスク（カビ等）があり、緊急介入が必要な状態。 | 相転移リスク、強制割り込み |

## 3. 社会的状態 (Social State)
他者との関わり方や社会的リソースの接続状態。

| 状態名 | 定義・特徴 |
| :--- | :--- |
| **遮断 (Isolation)** | 他者からの干渉を物理的・デジタル的にブロックした状態。 |
| **受容 (Available)** | 連絡があれば応答するが、能動的な交流はしない状態。 |
| **交流 (Interaction)** | 他者と能動的にコミュニケーションを行っている状態。 |
| **協力 (Collaboration)** | 共通の目標に向けて他者とリソースを共有している状態。 |
| **公共 (Public)** | 不特定多数の視線がある場にいる状態（カフェ、オフィス等）。 |
