# プロジェクト内容把握資料の構成案

## プロジェクト概要

このプロジェクトは以下の特徴を持っています：

1. **プロダクト**: iOS/watchOS向け「状態管理ツール」 - 測定と介入の記録に特化したロガー
2. **開発手法**: マルチエージェントアーキテクチャによる開発 - 「観点の補充」理論
3. **バージョン管理**: v1（MVP）/ v2以降の明確な機能境界
4. **ワークフロー**: Phase 1〜8の段階的開発プロセス

---

## 提案する資料構成

### 1. プロジェクト概要（Overview）
| 項目 | 内容 |
|:---|:---|
| **目的** | 新規参加者・開発者がプロジェクトの全体像を素早く把握 |
