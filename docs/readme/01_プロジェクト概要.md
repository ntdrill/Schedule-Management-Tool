# プロジェクト概要（Overview）

## 目的

本ドキュメントは、新規参加者・開発者がプロジェクトの全体像を素早く把握することを目的としています。

---

## 1. プロダクトコンセプト

### 「測定と介入の記録」に特化したロガー

本プロジェクトは、iOS/watchOS向けの**状態管理ツール**です。

従来のカレンダーアプリやタスク管理ツールとは異なり、**未来の計画（スケジューリング）を行わず**、以下に集中したアプローチを取ります：

| 焦点 | 説明 |
|:---|:---|
| **「今」の測定** | 測定モードのON/OFFにより、現在の状態を記録 |
| **「今」の対処行動** | 行った対処行動（介入）とその効果を記録・評価 |

> **Note**: タイムラインUI、状態の配置（スケジューリング）はv2以降で実装予定。

---

## 2. バージョン戦略

本プロジェクトは明確なバージョン境界を持っています：

| バージョン | 位置づけ | 主な特徴 |
|:---|:---|:---|
| **v1（現行）** | MVP（最小実用製品） | 測定と記録に集中、ローカル保存 |
| **v2以降** | 拡張版 | カレンダーUI、LLM連携、クラウド同期 |

## 3. 技術スタック

### プラットフォーム

| 項目 | 採用技術 |
|:---|:---|
| **対象OS** | iOS (iPhone) / watchOS (Apple Watch) |
| **言語** | Swift (SwiftUI) |
| **データ保存** | SwiftData または Core Data（ローカル保存・単一ユーザー） |

### センサー連携

| データ種別 | 取得元 | 取得データ |
|:---|:---|:---|
| **ユーザー状態** | HealthKit (Apple Watch) | 心拍数、HRV、活動量 |
| **環境状態** | SwitchBot API (iOS経由) | 室温、湿度 |

> **v2以降で追加予定**: iCloud (CloudKit) 同期、CO2濃度など詳細な環境センサー

## 4. v1 実装機能スコープ

### A. 測定モード管理 (Measurement Control)

- **機能**: 測定状態のON/OFF切り替えスイッチ
- **ON時**: HealthKit/SwitchBotからのデータ収集をアクティブ化し、バックグラウンドで記録
- **OFF時**: データ収集を停止し、バッテリーとリソースを節約
- **UI**: Watch/iOS共にメイン画面に大きなトグルボタンを配置

### B. 期待状態・状態入力 (State Input)

- **機能**: 「現在目指している状態（期待状態）」の選択と、現在の主観状態の記録
- **入力方式**: リストから「今のターゲット」を選択（選択しなくても測定は可能）
- **段階評価**: 数値ではなく段階（例: 1〜5、Good/Bad）で現在の感覚を記録

### C. 対処行動と評価 (Action & Evaluation)

- **機能**: 対処行動（タスク）の実行記録と評価
- **フロー**:
  1. **Select**: プリセットされた対処行動リストから選択（例：「深呼吸」「パルスシフト」）
  2. **Start/Stop**: 開始と終了をタップ（タイムスタンプ記録）
  3. **Evaluate**: 終了時に効果と状態変化を段階評価で入力
- **目的**: 行動と前後のデータ（センサー値＋主観評価）をセットで保存

### D. データ収集と紐付け (Data Logging)

- **収集データ**:
  - **客観データ**: 心拍数、室温、湿度（センサー連携）
  - **主観データ**: ユーザーが入力した段階評価
  - **コンテキスト**: 測定モード状態、選択中の期待状態、実行中の対処行動
- **出力**: iOSアプリ上で時系列のログまたはグラフとして確認可能

### E. 通知 (Notification)

- **方式**: ローカル通知（UserNotifications framework）
- **トリガー例**:
  - 測定モードONのまま長時間経過した場合の確認
  - 対処行動中の経過時間通知

## 5. デバイス役割分担

| 機能 | Apple Watch | iPhone |
|:---|:---|:---|
| **監視対象** | ユーザー状態 (心拍, HRV, 動き) | 環境状態 (室温, 湿度) |
| **測定頻度** | 常時・高頻度 (バックグラウンド) | 設定に基づく定期取得 |
| **通知** | 主体 (振動で介入) | 補助 |
| **入力** | 簡易回答 (Yes/No, 段階評価) | 詳細記録 (設定, プリセット管理) |
| **表示** | 今の状態・直近データ | ログ全体, 分析グラフ |

## 6. 画面構成

### Apple Watch（メイン操作端末）

| 画面 | 内容 |
|:---|:---|
| **Main View** | 現在の心拍数・室温表示、測定ON/OFFトグル、期待状態表示 |
| **Action View** | 対処行動リスト（プリセット）、実行中のタイマー・終了ボタン |
| **Feedback View** | Yes/No または段階評価ボタン |

### iOS（設定・閲覧・補完端末）

| 画面 | 内容 |
|:---|:---|
| **Dashboard** | Watchと同様のコントロール＋SwitchBotデータ表示 |
| **History/Log** | 収集データ（バイタル、室温、行動、評価）の時系列表示 |
| **Settings** | SwitchBot APIトークン設定、対処行動・期待状態プリセットの管理 |

---

## 7. 技術方針（v1/v2共通）

| 方針 | 説明 |
|:---|:---|
| **Local First** | サーバー不要、データは端末内（SwiftData）に保存 |
| **Watch Centric** | ユーザー状態の測定と簡易入力はWatch単体で完結 |
| **Trigger Sync** (v2以降) | 変化量が大きい時のみ通信、バッテリー節約 |
| **Flexible Sampling** | センサー取得頻度はユーザー設定可能 |

## 8. v2以降で実装予定の機能

以下の機能はv1スコープ外であり、v2以降で実装予定：

### UI/UX
- タイムラインUI（DAWライクな表示）
- 状態の配置（スケジューリング）
- ドラッグ＆ドロップ操作

### 高度な判断・処理
- LLMによる判断・推論
- 代替タスクの自動算出
- 再スケジューリング
- 全体エントロピーの計算

### 状態管理
- 社会的状態の管理
- 危篤状態の閾値判定・自動検知
- 危篤状態からのリカバリープラン生成

### データ同期・センサー
- iCloud (CloudKit) によるデバイス間同期
- CO2濃度など詳細な環境センサー
