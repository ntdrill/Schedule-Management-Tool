# 進捗・履歴（Progress & History）

## 目的

本プロジェクトの進捗状況、過去の意思決定、および作業履歴を追跡可能にするための指針と情報源を示します。
このファイル自体が進捗を管理する場所ではなく、**「どこを見れば進捗がわかるか」**を案内するガイドです。

---

## 1. 進捗情報の保管場所

日々の詳細な進捗やタスクの状態は、以下のディレクトリで管理されています。

### 1.1 進捗報告（Reports）
各エージェントからの報告が集約される場所です。

- **場所**: `進捗管理agent/進捗報告受付/`
- **内容**: 日次の作業報告、フェーズ完了報告、週次サマリー
- **ファイル形式**: `YYYYMMDD_[件名].txt`

### 1.2 タスク管理（Task Management）
実装タスクのステータス管理場所です。

- **場所**: `Agent_workspace/Task_Management/`
  - `01_Proposals/`: 提案されたタスク
  - `02_Active/`: 現在進行中のタスク
  - `03_Completed/`: 完了したタスク
  - `04_Archive/`: 過去のタスクや古い提案のアーカイブ

### 1.3 ワークフロー（Workflow Queue）
開発フェーズごとの手順書です。

- **場所**: `Agent_workspace/Agent_maneger/data/Agent Workflow Queue/`
- **内容**: Phase 1〜8 の各ステップ定義

---

## 2. 進捗管理プロセス

本プロジェクトでは **進捗管理agent** が中心となって進捗を可視化します。

1. **報告**: 各エージェントは作業完了時に報告書を作成し、`進捗報告受付` ディレクトリに提出します。
2. **集約**: 進捗管理agentは報告を確認し、週次サマリーやフェーズ完了レポートを作成します。
3. **可視化**: プロジェクトの状態（遅延、完了、問題発生）を明確にします。
