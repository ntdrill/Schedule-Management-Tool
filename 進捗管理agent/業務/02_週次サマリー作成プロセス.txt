# 02_週次サマリー作成プロセス

## 目的
散在する進捗報告を定期的に集約し、全体像を把握可能にする

## ステータス
予定

---

## 内容

### 1. サマリー作成タイミング
- 毎週末（日曜日）または週明け（月曜日）
- 重要なフェーズ完了時は臨時サマリーを作成

### 2. サマリーテンプレート

```
# 週次サマリー: YYYY/MM/DD 〜 YYYY/MM/DD

## 完了したタスク

| タスク | 担当エージェント | 完了日 |
| :--- | :--- | :--- |
| [タスク名] | [エージェント名] | YYYY/MM/DD |

## 進行中のタスク

| タスク | 担当エージェント | 進捗 |
| :--- | :--- | :--- |
| [タスク名] | [エージェント名] | [進捗状況] |

## 発生した問題

| 問題 | 影響範囲 | 対応状況 |
| :--- | :--- | :--- |
| [問題名] | [影響範囲] | [対応状況] |

## 来週の予定
- [ ] 予定1
- [ ] 予定2

## 備考
- （任意）
```

### 3. 保存先
- `進捗管理agent/サマリー/`（新規作成）
- ファイル名: `週次サマリー_YYYYMMDD.txt`

### 4. 情報収集元
- `進捗管理agent/進捗報告受付/` 内の報告
- `Agent_workspace/Task_Management/02_Active/` のタスク状況
- `Agent_workspace/Task_Management/03_Completed/` の完了タスク
