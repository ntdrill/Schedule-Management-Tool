# スケジュール管理ツール

予定オブジェクトと実行オブジェクトを分離したスケジューリングツールの実験的実装です。

## 起動方法

### 方法1: ローカルHTTPサーバーを使用（推奨）

1. `start-server.bat` をダブルクリックします
2. ブラウザで `http://localhost:8000` を開きます

### 方法2: 直接HTMLファイルを開く

HTMLファイルを直接開く場合、CORSエラーを回避するためにmoduleタイプを削除してあります。
`index.html` をブラウザで直接開いてください。

### 方法3: VS CodeのLive Serverを使用

1. VS Codeで「Live Server」拡張機能をインストール
2. `index.html` を右クリック → 「Open with Live Server」

## データのリセット

- ヘッダーの「データをリセット」ボタンをクリック
- または、URLに `?reset` を追加してアクセス

## 主な機能

1. **テンプレート辞書**: タスクやチェックリストのテンプレートを管理
2. **予定オブジェクト**: 不変のスケジュール意図として予定を作成
3. **実行オブジェクト**: 実際の実行記録を別オブジェクトとして保存
4. **状態管理**: 期待状態と実際の状態を比較して効果を測定
5. **代替タスク検索**: 前提条件に基づく代替タスク提案（基本実装）

## 便利ツール

### 状態エディタ
`state-editor.html` を開くと、プログラミング形式の入力なしで状態を設定できます。

- フォームで選択 → 自動的にテキスト形式に変換
- コピーボタンで簡単にメインアプリに貼り付け
- ユーザー状態・環境状態・社会的状態を視覚的に編集

**使い方:**
1. `state-editor.html` をブラウザで開く
2. プルダウンやテキストボックスで状態を選択
3. 「コピー」ボタンでテキストをコピー
4. メインアプリの状態入力欄に貼り付け

## トラブルシューティング

### テンプレートが表示されない場合

1. ブラウザのコンソール（F12）でエラーを確認
2. 「データをリセット」ボタンでストレージをクリア
3. ページをリロード（Ctrl+F5）

### CORSエラーが発生する場合

- ローカルHTTPサーバーを使用してください
- または、Chromeの場合は `--allow-file-access-from-files` フラグを付けて起動
